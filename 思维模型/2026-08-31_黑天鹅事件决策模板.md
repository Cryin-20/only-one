## 一句话主旨

黑天鹅到来时，正确反应不是"做点什么"而是"先停下来 + 按剧本执行"——剧本里的每一步都在黑天鹅前已经验证过、演练过、写进检查清单里。

## 可复用原则（决策时引用，8 条）

1. **黑天鹅不可预测，但可准备**：COVID-03-12、LUNA-05、FTX-11、2025-10 清算级联——四个事件事前没有任何主流模型准确预测过；但事后看，每个事件都有"事前可识别的脆弱结构"（杠杆 + 集中度 + 单一假设 + 路径依赖）。**反脆弱不在于"猜对"，在于"事前让结构扛得住事后"**。
2. **反脆弱 = 不被黑天鹅击垮 + 从中获益**：Bridgewater 2008 盈利 9.5%（结构性对冲）、Berkshire 2008 净利 -31% 但存活并加仓、2025-10 清算级联中费率套利团队反而加仓（手续费折扣 + 波动率溢价）——三者都用"结构性优势"在危机中或减亏或获利。**反脆弱不是"扛住"——是"扛住 + 利用"**。
3. **黑天鹅中最大的敌人是"必须立刻做"的冲动**：LUNA 崩盘期间 24 小时内 40 万用户爆仓（BitMEX/币安），绝大多数亏损来自"加仓抄底"——把 A 股的"跌 43% 抄底"经验套到加密圈（实际可腰斩再腰斩）。**黑天鹅的 5 分钟规则：先停 60 秒，再决定**——承自《认知偏差全谱》§4 情绪启发式反例。
4. **黑天鹅前 vs 黑天鹅中 vs 黑天鹅后 = 三种完全不同的决策模式**：黑天鹅前（基于 regime）→ 黑天鹅中（基于剧本）→ 黑天鹅后（基于复盘）。**不能在黑天鹅中用 regime 决策（信息不全 + 情绪干扰），也不能在黑天鹅后用剧本决策（已经发生）**。
5. **剧本必须包含"什么都不做"的选项**：5 个剧本里每个都有"不行动"作为合法选项（不下单、不提币、不抄底、不平仓、不改策略）。**反脆弱的"不行动" = 保留可选择性 = 等待信息清晰**——承自《反脆弱决策清单》§A8 "能 sleep on it 24 小时吗"。
6. **结构改造 > 短期判断**：黑天鹅中能"立刻平仓"很重要，但更值钱的是事前把"不可立刻平仓"的结构改掉——LUNA 崩盘时链上拥堵让 USDT 提币延迟 12h+，FTX 崩盘时客户资产被冻结 8 天。**剧本不是"危机时怎么做"，是"危机前怎么把暴露改到不会用到剧本"**。
7. **公开剧本 + 定期演练 > 隐藏剧本**：Berkeley 经济学教授的开放工作流、Munger 的"反过来想"、达利欧的《Principles》——把决策过程外化、写下来、定期演练，比"靠天才"更反脆弱。**剧本写在纸上 = 让未来的你在情绪下能查表**。
8. **"事后聪明"是反脆弱的最大错觉**：每次黑天鹅后都有人说"我早就知道"——LTCM 1998 崩盘后有人说"我早就知道俄罗斯会违约"、FTX 2022 崩盘后有人说"我早就知道 SBF 在挪用"、2025-10 清算后有人说"我早就知道高杠杆会爆"。**事后叙事 ≠ 事前判断**——承自《失败案例集》§4.1 Munger "我没有事后聪明偏差" 的反例。

## 核心逻辑链（5 步）

1. **前提**：黑天鹅（Mandelbrot 肥尾 α<3 + Taleb "未预期但重大" + 影响事后看"显然"但事前"完全不可能"）会反复出现——加密市场过去 5 年就有 COVID-03-12 / LUNA-05 / FTX-11 / 2022-11 三箭 / 2025-10 清算级联 / 2025-02 Bybit 盗窃等多次结构性黑天鹅；研究这些事件的共性能找到"事前可准备的剧本"。
2. **机制一（黑天鹅分类）**：按起源分 4 类——金融（FTX / 3AC / Archegos）、疫情/系统（COVID / 2020-03）、技术/算法（LUNA 算法稳定币）、政策/监管（中国 2021-09 禁令）。**每类有特定的早期信号**——金融（杠杆 OI 创新高 / 单一对手方集中度）/ 疫情（lockdown 信号）/ 技术（Anchor 20% APY 持续）/ 监管（主流媒体连续报道）。**黑天鹅发生 24-72 小时前常有"似是而非的信号"——剧本的价值是把这些信号"映射到应对"**。
3. **机制二（剧本套用）**：每个剧本 6 段格式——① 事件概况（时间 + 触发 + 规模）② 时间线（24h / 1 周 / 1 月关键节点）④ 我的角色（加密交易者 / 量化项目 / CEX 用户 / DeFi 参与者）⑤ 决策点（每个时点的具体动作选项）⑥ 应对（决策 + 动作）⑦ 复盘（决策质量 + 机制有效性 + 心理影响）。
4. **机制三（事前准备 vs 事中执行）**：事前（杠铃 + 冗余 + 可选择性 + 流动性储备 + 心理建设）= 让剧本不启动；事中（先停 60s + 信息源确认 + 风险敞口评估 + 决策剧本套用 + 行动检查清单）= 让剧本正确执行；事后（决策质量复盘 + 机制有效性复盘 + 心理影响复盘）= 让剧本迭代。
6. **结果**：5 个真实剧本 + 5 大事前准备 + 5 步事中决策 + 3 类事后复盘 = 一份从"事前到事后"完整的黑天鹅决策工具包。
7. **行动指引**：① 每月读一次 5 个剧本（保持记忆）② 每季度演练一次"如果明天发生 X，我第一步做什么" ③ 每次真实事件发生后用 3 类复盘填一份复盘报告（写在《决策记录模板》里）④ 每年迭代剧本（基于当年新事件）⑤ 把剧本的"行动检查清单"贴到交易终端 / 钱包界面 / 飞书置顶。
8. **诚实声明**：① 我**没有亲身经历** COVID-03-12、LUNA-05、FTX-11 三大事件；所有细节来自 Multicoin Capital / MIT-NBER / Wikipedia / Bloomberg / Coindesk 公开报道的二手复盘。② 我**没有亲身经历** 2025-10 清算级联，但 100 USDT 项目正在运行 watcher 观测费率，对该事件的反应是基于论文 + 公开数据的合理推断。③ 剧本 E（未来可能）完全基于"如果 X 发生，按 Y 应对"的结构化推演，未对应已发生事件。④ 所有具体数字来自 Wikipedia + Bloomberg + Coindesk + SSRN + Galaxy + arxiv + 公开法庭文件交叉验证。

### 第一章　黑天鹅的 4 类分类与早期信号

#### 1.1 4 类分类（按起源）

| # | 类别 | 定义 | 真实例子 | 共性特征 |
| --- | --- | --- | --- | --- |
| 1 | **金融脆弱型** | 由金融体系内生的杠杆/对手方/集中度引爆 | 1998 LTCM / 2021 Archegos / 2022 3AC / 2022 FTX / 2025-10 清算级联 | 杠杆 + 单一对手方 + 流动性错配 + 跨所跨协议传染 |
| 2 | **外部冲击型** | 由外部事件触发（疫情、战争、自然灾害） | 2020-03 COVID / 2022 俄乌战争 | 短期价格暴跌 + 流动性危机 + 跨资产传染 |
| 3 | **算法/技术型** | 由协议/算法设计缺陷引爆 | 2022-05 LUNA / 2022 stETH 脱锚 / 2025-02 Bybit 多签盲签 | 机制不可持续 + 套利反转 + 链上拥堵放大损失 |
| 4 | **政策/监管型** | 由政府/监管层政策反转引爆 | 2013-12 中国五部委禁令 / 2021-09 中国全面禁止 / 2024 MiCA 稳定币条款 | 短期价格冲击 + 长期算力/资本迁徙 + 叙事反转 |

#### 1.2 各类的早期信号（事前 24-72h 可识别的"似是而非"信号）

**金融脆弱型**：
- 永续合约 OI 创新高 + funding rate 极端值（>0.1%/8h 或 <-0.05%/8h）
- 单一交易所/做市商持仓占比异常（Coinglass/Coinalyze 可查）
- 跨所价差扩大（>50 bps BTC、>100 bps ETH）
- 主流媒体（FT/Bloomberg/WSJ）开始报道某家机构财务问题
- 交易所提币延迟 + 客服响应变慢

**外部冲击型**：
- WHO/CDC 流行病警告 + 多国政府升级防疫响应（COVID 1 月-2 月信号）
- 大宗商品/能源价格异常（俄乌战争前 Brent 异常）
- 央行紧急会议 + 突发降息（COVID 3 月初 Fed 紧急降息 50bp）

**算法/技术型**：
- 协议 APY/收益异常持续 > 数月（LUNA Anchor 20% APY 持续 18+ 月）
- TVL 单一协议占比 > 30%
- 链上 oracle/预言机节点数 < 5 个（中心化风险）
- 协议升级/参数调整未公开审计

**政策/监管型**：
- 主流央媒/官媒连续 3+ 天报道（2021-09 中国禁令前 1 周信号）
- 立法机构公开听证会 + 行业代表被传唤
- 行业协会/自律组织"风险预警"通报
- 跨部门联合公告（央行 + 财政部 + 证监会 等多部委联合）

#### 1.3 早期信号 → 剧本的"触发器映射"

任何信号出现 = 启动对应剧本的"早期阶段"动作（不进入"危机中"剧本）。**信号不是预测——是事前准备的依据**。承自《反脆弱决策清单》§A3 情绪启发式反例："在饥饿、愤怒、狂喜、疲惫时推迟 30 分钟"——同样地，"在信号出现时开始准备，不是立刻行动"。

### 第二章　剧本 A：2020-03-12 COVID 暴跌（加密市场结构崩溃）

**事件概况**：2020-03-12（周四）北京时间晚 21:00-22:30，BTC 从约 $8,000 在 6 小时内跌至 $3,600（-55%），随后 24 小时内最低触及 $3,800 区间（vs 19 天前高点 $10,500）。同期标普 500 触发 4 次熔断（3-9 / 3-12 / 3-16 / 3-18），单周跌幅 -12%（2008 以来最大）。**加密市场的特殊性**：BitMEX 订单簿一度只剩约 2,000 万美元买单、却有超 2 亿美元多头待清算；BitMEX 与 Coinbase 价差一度超过 $500；MakerDAO 清算机器人因 gas 费不动态调整而失效，有人以 $0 拍得 $800 万美元 ETH 抵押品（Multicoin Capital 第一手复盘）。

**时间线（24h 关键节点）**：
- **3-11 23:00 UTC**：WHO 宣布 COVID-19 为"全球大流行"（pandemic）——**信号已公开，但市场仍认为"可控"**
- **3-12 13:00 UTC**：特朗普总统宣布"欧洲旅行禁令"，美股期货触发 5% 跌停限制
- **3-12 19:00 UTC**：BTC 从 $7,800 开始第一波下跌，1 小时内跌至 $6,500
- **3-12 21:00 UTC**：第二波下跌，BTC 30 分钟内从 $6,500 跌至 $4,000（BitMEX 主导）
- **3-12 21:30 UTC**：BTC 触及当日低点 $3,600（部分交易所瞬时），BitMEX 暂停交易"维护"
- **3-12 22:00 UTC**：Coinbase / Binance / Bitfinex 全面暂停部分订单簿
- **3-13 08:00 UTC**：价格反弹至 $5,500（联储紧急降息 0.5% + 财政刺激预期）
- **3-13 14:00 UTC**：再次下跌至 $4,800，第二日波动率收窄
- **3-16 09:00 UTC**：标普熔断 4/4，BTC 跌至 $5,200（周日开盘后继续跌）
- **3-18 11:00 UTC**：标普熔断 4/4，BTC 跌至 $4,900（联储再降息 + 无限 QE 预期）
- **3-19 06:00 UTC**：BTC 触及 $4,400 月底低点
- **3-20 起**：全球央行放水 + 美联储无限 QE + 财政 2 万亿刺激，BTC 反弹至 $6,800

**我的角色**（假设你是 2020-03 正在运行的加密项目）：① 加密交易者（中长线持仓 + 部分杠杆）② 量化项目（运行中，可能涉及永续合约）③ CEX 用户（资产在交易所）④ DeFi 参与者（MakerDAO 抵押 ETH）

**决策点 + 应对**：

| 时点 | 决策点 | 选项 A（行动） | 选项 B（不行动） | 选项 C（反脆弱） |
| --- | --- | --- | --- | --- |
| **3-11 23:00（信号）** | WHO 宣布全球大流行，要不要减仓？ | 减仓 30%（卖出部分多头） | 不动（保留敞口） | **准备剧本**：打印检查清单 + 设好熔断价 + 准备好 USDT 稳定币 |
| **3-12 13:00（欧洲禁令）** | 美股期货跌停，要不要平仓？ | 全部平仓 | 不动 | **检查杠杆 + 提高稳定币比例到 30%+** |
| **3-12 19:00（第一波）** | BTC 从 7,800 跌到 6,500，要不要加仓抄底？ | 加仓 20% | 不动 | **检查交易所提币是否正常（避免 USDT 提不出）** |
| **3-12 21:00（第二波）** | BTC 30 分钟 -38%，要不要继续加仓？ | 不加仓（保留现金） | 不动 | **什么都不做——剧本里"什么都不做"是合法选项** |

| **3-16 / 3-18（标普熔断）** | 多次熔断，要不要恐慌？ | 不恐慌 | 不动 | **保持纪律 + 准备 3-19 后续下跌的可能** |
| **3-19 06:00（月底低点）** | BTC 跌到 4,400，要不要抄底？ | 抄底 10% | 不动 | **美联储无限 QE 落地后 + 财政刺激后 → 结构性反弹开始 → 少量建仓** |

**复盘**（从 2020-04 角度看哪些决策有效）：
- ✅ **选项 C（反脆弱）系列最优**：提前准备剧本 + 提高稳定币比例 + 检查交易所提币状态——这些都是"不试图预测，只保持结构优势"的反脆弱动作
- ❌ **选项 A（行动）系列绝大多数失败**：减仓 30% 后错过反弹（3-20 起 BTC 从 $4,400 涨到 $6,800 +54%）；加仓 20% 抄底在 6,500 在 -50% 后继续亏损
- ⚠️ **抄底 10% 的选项 C 在 3-19 月底低点是最优**：3-19 抄底后 6 个月内 BTC 涨到 $12,000（+170%）

**机制层复盘**：
- 加密市场结构在 3-12 出现"链上拥堵 + 矿机关机 → 跨所套利资金动不了 → 价差无法收敛 → 做市商集体撤退 → 单一交易所深度断裂"的级联（Multicoin Capital）
- 教训：极端行情里，你策略依赖的每一个"市场结构假设"（能平仓、能转账、有对手方、预言机正常）会**同时失效**——承自《失败案例集》§1.4 Bitcoin 网络层反脆弱 ≠ 任何比特币相关业务的反脆弱
- 行动启示：① 交易所资产分散（不 100% 放一个所）② API key 最小权限（不开提币）③ 盈利定期归集到自托管钱包 ④ 监控交易所状态

**心理影响复盘**：
- COVID-03-12 后，加密行业整体出现"幸存者偏差"——活下来的人觉得自己"扛住了"，但绝大多数"扛住" = "没动"，而不是"做对了"
- 教训：① 不要把"幸存"当成"决策正确"——这是《认知偏差全谱》§F "幸存者偏差"的反例 ② 黑天鹅中"不动"是被低估的反脆弱动作

### 第七章　黑天鹅前的 5 大准备（事前剧本）

> 承自《反脆弱决策清单》§3.1 投资领域 11 条精选 + 《杠铃配置模板》+ 100 USDT 项目 L1 风控层

#### 7.1 杠铃配置（不要中段）

**加密版杠铃示例**（基于 100 USDT 项目结构）：
- **极保守端 70%**：USDT/USDC 稳定币 + 短债基金 + 跨所分散（CEX 50% / 自托管 50%）
- **极激进端 30%**：BTC/ETH 现货（仅持有，不杠杆）+ delta 中性套利（费率套利 / 期现套利）
- **0% 中段**：不持有山寨币 / 不使用杠杆 / 不参与 ICO / 不参与流动性挖矿

**传统版杠铃示例**：
- **极保守端 80%**：现金 + 国债 + 6 个月生活费
- **极激进端 20%**：高 conviction 单一标的（不动摇）+ 自我毁灭性实验（10%）
- **0% 中段**：不持有"看起来稳"的中端资产（REITs / 长期债券 / 中小盘股）——中段 = 看起来稳 + 实际脆弱

#### 7.2 冗余（为未知付的保费）

**4 类冗余**：
- **现金冗余**：6-12 个月生活成本（不变现）+ 30% 投资资产稳定币比例
- **资产冗余**：3+ 个独立资产类别 + 3+ 个独立交易所 + 自托管 + 跨司法管辖区
- **人脉冗余**：跨领域、跨代际、跨文化的朋友圈（承自《失败案例集》§4.1 Munger 圈层冗余）
- **技能冗余**：多个独立维度（一个失败不影响整体——如不只是量化交易者，也是程序员 + 投资者 + 写作者）

#### 7.3 可选择性（保留未来能做什么的自由）

**5 项可选择性保留**：
- **不签 5 年独家合同**——不绑死单一雇主 / 单一平台
- **不锁定单一技能**——保留 2-3 个相互独立的能力
- **不 All-in 单一策略**——至少 2-3 个不同方向的实验
- **不持有"无法退出"的资产**——流动性差的资产降低到 < 30%
- **保留否决权/退出权**——任何不可逆决定前先保留"不走"的选项

#### 7.4 流动性储备（黑天鹅中"跑得出来"的能力）

**加密版流动性储备清单**：
- ✅ 每个 CEX 提币功能正常（每月测试一次）
- ✅ 提币白名单已设置（限制提币地址）
- ✅ API key 最小权限（只开交易、关闭提币）
- ✅ 盈利定期归集到自托管钱包（Ledger / Trezor）
- ✅ 跨所有 CEX 的提币时间记录（哪个所提币最快）
- ✅ 链上资金移动的备用 gas（钱包留 0.1 ETH 等）
- ✅ OTC 出场渠道（如果交易所暂停提币）
- ✅ 保险覆盖（Nexus Mutual / InsurAce / Sherlock 等）

#### 7.5 心理建设（黑天鹅前"准备好心理"）

**5 项心理建设**：
- **接受"不知道"**——任何"我觉得这次不一样"的判断都可能是结果偏差
- **接受"会亏"**——事先规划好"可承受亏损"的上限（如 -30%），到了就执行
- **接受"不动"**——黑天鹅中"什么都不做"是被低估的反脆弱动作（承自 §剧本 A 复盘）
- **定期演练**——每季度演练一次"如果明天发生 X，我第一步做什么"
- **写下来**——剧本写在纸上 + 贴到交易终端 + 贴到钱包界面 + 飞书置顶

### 第八章　黑天鹅中的 5 步决策模板

> 承自《反脆弱决策清单》§3.3 项目领域 10 条 + §4 决策中校验清单

| 步骤 | 动作 | 关键问题 | 一句话反例 |
| --- | --- | --- | --- |
| **1. 先停 60 秒** | 不做任何操作 60 秒 | 我现在的情绪状态是什么？ | 愤怒/狂喜/疲惫 → 推迟 30 分钟 |
| **2. 信息源确认** | 检查 3 个独立信息源（不是社交媒体） | 这个消息有官方确认吗？二手验证了吗？链上/法币价格一致吗？ | 单一信息源 → 默认不信；3 个独立信息源 → 可信 |
| **3. 风险敞口评估** | 计算当前总敞口 + 杠杆 + 集中度 | 我的最大单笔损失是多少？能扛住几个 -30% 事件？ | 单笔 > 总资产 30% → 立刻减仓 |

| **5. 行动检查清单** | 按剧本的执行清单逐项打钩 | 我是否每一步都按检查清单执行？有没有跳过任何步骤？ | 跳过步骤 = 大概率会犯错误 |

**特别触发器**（满足任一立刻停下）：
- 任何"等等再想"的瞬间 → **立刻想**
- 任何"应该没问题"的瞬间 → **正是问题最大处**
- 任何"再追加一点就能翻盘"的瞬间 → **凹性暴露的标准剧本**
- 任何"别人都在做"的瞬间 → **羊群效应 + 反向思考**
- 任何"现在就抄底"的瞬间 → **承自 COVID-03-12 / LUNA / 2025-10 三个剧本的复盘**

**5 个维度**（每维 1-5 分）：

5. **执行纪律**：我是否按检查清单逐项执行？100% 执行 = 5，跳过步骤 = 2

#### 9.2 机制有效性复盘

**5 个维度**：
1. **冗余设计**：我的冗余设计是否在事件中起作用？起作用 = 5，没起作用 = 1

3. **杠铃配置**：我的杠铃配置是否兑现反脆弱？兑现 = 5，集中在中段 = 1
4. **流动性储备**：我是否"跑得出来"？顺利 = 5，被锁 = 1
5. **结构改造**：本次事件是否暴露新的结构脆弱？发现并整改 = 5，假装没看见 = 1

#### 9.3 心理影响复盘

**5 个维度**：
1. **幸存者偏差**：我是否把"幸存"当成"决策正确"？区分清楚 = 5，混淆 = 2
2. **沉没成本**：我是否因为"已经亏了"继续投入？重新评估 = 5，沉迷于回本 = 1
3. **过度自信/自卑**：我是否因为这次事件变得更激进/更保守？保持中性 = 5，摇摆 = 1
4. **认知更新**：我是否把这次事件沉淀为新的认知？写下来 = 5，遗忘 = 1
5. **长期视角**：我是否仍然在"长期起伏大于短期高低"的视角下行动？是 = 5，否 = 1

### 第十章　个人 vs 量化策略——黑天鹅中的不同应对

| 维度 | 人工决策 | 量化策略 |
| --- | --- | --- |
| **黑天鹅前** | 心理准备 + 剧本演练 + 杠铃配置 | 系统化检查清单 + 自动化熔断 + 风控层覆盖 |
| **黑天鹅中** | 5 步决策模板（§第八章） | 熔断自动触发 + 不依赖人工干预 + 保留可选择性 |
| **黑天鹅后** | 3 类复盘（§第九章） | 自动日志 + 自动归因 + 自动调整风控参数 |
| **优势** | 灵活应对 + 多维度判断 | 不被情绪干扰 + 严格纪律 + 24/7 监控 |
| **劣势** | 情绪 + 认知偏差 + 行动延迟 | 极端行情 API 断连 + 流动性坍塌时无法成交 |
| **关键反脆弱** | 保留"不动"的选项 | 保留"暂停策略"的选项（熔断 = 暂停） |
| **最大风险** | "必须做点什么" 的冲动 | "程序可能失效" 的盲信 |

**关键交叉启示**：
- **人工 + 量化 = 互补**：人工负责"剧本套用" + "5 步决策" + "复盘沉淀"，量化负责"7×24 监控" + "熔断执行" + "数据记录"
- **100 USDT 项目 L1 风控 + L6 监控层**就是这种互补的工程化体现——承自《自动量化项目架构初稿 v0.1》七层架构
- **人工的最大反脆弱 = "允许自己不动"**（承自 §剧本 A 复盘 + §黑天鹅中决策模板 步骤 1）
- **量化的最大反脆弱 = "允许程序暂停"**（熔断 ≠ 关掉 = 暂停 + 等待 + 人工介入）
