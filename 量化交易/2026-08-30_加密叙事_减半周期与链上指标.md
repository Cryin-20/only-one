## 可复用原则（决策时引用）

1. **叙事是有传染性的病毒，指标是有传染性的数值**：Shiller 2019《Narrative Economics》指出叙事的传播类似流行病，有"感染率 / 康复率 / 免疫期"——加密叙事的"叙事更替"比股市快 5–10x（2017 ICO → 2020 DeFi Summer → 2021 NFT → 2022 LUNA 崩 → 2024 ETF → 2025 AI×Crypto）。**叙事是定性的解释变量，指标是定量的触发变量**——实战中用指标 trigger + 叙事解释 + 决策 record，不要"单看一个"。
2. **减半不是因果，是必要条件**：4 次减半 + 4 次"减半后 12–18 月顶部"的历史模式，**统计推断极其薄弱**（n=4 ≈ 弱规律）。但背后的经济学理由（供应减半 → 需求不变 → 价格压力上升）解释了这个机制的"必要性"。**减半不必然带来顶部，但减半构建了"供应紧张"的边界条件**——把它当成"日历上的供给事件"理解，而不是"日历上的预测事件"。
3. **PlanB S2F 模型已死，但稀缺性叙事没死**：S2F 在 2019–2021 间多次命中（2020-05 起涨 → 2021-11 $69k），但 2022 LUNA 崩盘后 BTC 跌到 $16k、模型预测 $100k+ 落空；Francis Tapon 2019 早指出 S2F 有 8 大缺陷。**教训**：单一静态公式无法捕捉动态系统——这是《系统思维与反脆弱》§3 杠杆点的直接体现。**S2F 是"密码朋克叙事的数学化"，不是"价格预测模型"**。
4. **链上指标能"事后精确"，不能"事前预测"**：MVRV / SOPR / NUPL / Pi Cycle / Puell 在事后都能精确定位 2013/2017/2021 顶部，但在事前 5–10 天才有信号。**承认"事后确认 > 事前预测"是工程纪律**——这对应《风险量化 VaR/CVaR/ES》§5"找脆弱性"哲学。
5. **2025-10 顶部 = 经典指标的"集体失声"事件**：arxiv 2607.26188（Bitcoin Runs on a Clock, 2026）+ Galaxy 2025 实证——Pi Cycle Top 4 次精确（2013/2017/2021/2025-04）后**在 2025-10 顶部首次未触发**；MVRV 仅 2.29（历史 2.93–5.91）；Puell < 4.0；Mayer Multiple < 2.4。**这次顶部 BTC 仍按减半 +525/546/534 天节奏到达（2024-04 减半 → 2025-10 顶部，534 天）**——价格"日历"还在，但"指标"已经哑火。**这意味着项目不能再依赖单指标，必须多维度交叉**。
6. **ETF 周期叠加减半周期 = 结构性平移，不是简单重复**：2024-01-10 现货 ETF 通过 + 2024-04-20 减半的双重事件，是历史上第一次。crypto.news 2026 实证：ETF 月度资金流量 > 矿工年产出一个数量级——ETF "买什么都涨 / 卖什么都跌"，把减半的"供应冲击"叙事边缘化。**"4 年周期没死，但被 ETF 平滑了"**——2025 顶部提前到 10 月、波动率大幅下降、回调幅度 -51%（vs 历史 -77%/-84%/-86%）。
7. **多指标强信号 > 单指标强信号**：MVRV + NUPL + Puell + Pi Cycle 同时进入红色区 = 强顶部信号（概率 > 80%）；任一指标独立触发 = 弱信号。**这对应《系统思维与反脆弱》§3 多杠杆点交叉验证**——任一杠杆点单独看是噪音，叠加看是信号。
8. **Phase 1 不看叙事不看指标，Phase 3 才集成**：100 USDT 项目的费率套利**不依赖方向**，叙事/指标触发对它没有直接影响——但**顶部区域需要收紧熔断 / 缩小仓位**（承自《风险量化 VaR/CVaR/ES》§7 L1 反向校准）。**Phase 1 跑费率套利，Phase 3 加入"周期日历 + 链上指标"作为熔断收紧条件**——这是工程纪律。
9. **"减半必涨"是迷信，但"减半前后费率异常"是事实**：减半前 6 月矿工抛售压力大（卖币买矿机/付电费），减半后 6 月矿工收入降 → 卖压降 → 链上稳定。**这影响费率套利的"减半窗口"决策**——减半后 1-3 月可能费率反向（看 2020-05 减半后 2020-08 费率短暂为负），但减半后 6-12 月是费率回升的甜蜜区。
10. **指标 = 滞后信号，叙事 = 领先信号**：链上指标反映"链上已发生的事"（已实现的盈利 / 已转移的币），叙事驱动"链上即将发生的事"（散户入场预期 / 机构配置预期）。**实战纪律**：用叙事识别"现在可能在什么周期阶段"，用指标确认"是否真的进入了那个阶段"——两者冲突时偏向指标（数据更可靠），但记录叙事冲突作为"未来认知更新"的输入。

## 核心逻辑链

1. **前提**：加密市场不是"随机游走"——它有 4 大叙事周期（减半 4 年 / ETF 数年 / 监管数年 / 技术叙事 6-18 月）+ 链上指标定量化（MVRV / SOPR / NUPL / Puell / Pi Cycle / Exchange Netflow / LTH-STH）的双重驱动。**叙事决定方向，指标决定幅度**——但 2025-10 后指标哑火，叙事主导。
2. **机制（叙事传播）**：Shiller 2019 叙事经济学——叙事是"会传染的病毒"，有"感染率 / 康复率 / 免疫期"。加密叙事的"康复期"特别短（叙事衰退比股市快 5–10x）。**单一叙事 → 多叙事竞争 → 新叙事取代**——每轮周期的核心叙事换一遍（货币 → 数字黄金 → 通胀对冲 → 主流化 → ETF → ?）。
3. **机制（减半）**：比特币每 210,000 区块（约 4 年）奖励减半——2009/2012/2016/2020/2024 已经历 5 次（创世 + 4 次减半）。**供应减半 → 矿工抛压减半 → 需求不变 → 价格压力上升**——这是"供应稀缺性"的直接表达。但**单次事件不构成周期**——4 次减半 + 4 次"减半后 12–18 月顶部"是经验规律，不是因果定律。
4. **机制（指标）**：链上数据把"市场参与者行为"量化——MVRV（市值/实现价值）衡量"全体持仓者的浮盈率"，SOPR 衡量"已实现盈亏比"，NUPL 衡量"未实现净盈亏占比"，Puell 衡量"矿工收入相对历史"，Pi Cycle 衡量"短期/长期均线偏离"，Exchange Netflow 衡量"交易所流入流出"。**每个指标都是"事后精确定位"工具，不是"事前预测"工具**。
5. **结果（2024-2025 周期特殊性）**：2024-01-10 现货 ETF 通过 + 2024-04-20 减半的双重事件，让 BTC 在 2024 年涨到 $100k+、2025 年延续至 $124,824（2025-10-09 ATH, arxiv 2607.26188）。**所有经典顶部指标（MVRV / Puell / Pi Cycle / Mayer Multiple / 5×2yr MA）在 2025-10 顶部前 5–10 天都未触发**——这是历史第一次。"4 年周期没死，但被 ETF 平滑"——crypto.news 2026 把它称为"cycle flattening"。
6. **结果（项目应用）**：100 USDT 项目的费率套利策略**不依赖方向判断**，叙事/指标对它没有直接触发作用——但**顶部区域需要收紧熔断 / 缩小仓位**（L1 风控 + L6 监控的"周期日历 + 链上指标告警"分支）。**Phase 1 费率套利正常跑，Phase 3 加入"顶部收紧"作为动态熔断线**。**叙事日历 + 链上指标 = 工程化的"市场环境感知"**。
7. **决策口诀**：单指标触发 = 弱信号；多指标叠加 = 强信号；指标 + 叙事同向 = 强信号；指标 vs 叙事冲突 = 谨慎（以指标为准，记录叙事）；2025-10 后 = 指标哑火期，必须用 ETF flow + 机构持仓 + 宏观（Fed 利率 / MSTR 持仓）+ 减半日历 4 维度交叉判断。

#### 第三章　叙事经济学（Shiller 2019）

**3.1 叙事经济学的核心观点**

**4.1 4 次减半史（承自 BitcoinSuisse + Bitbo + VanEck + CoinLedger + Investopedia + Braiins 交叉验证）**

| 减半 | 日期 | 区块奖励变化 | 当日价格 | 减半后 150/180 日价格 | 减半后 12-18 月顶部 |

**关键观察**：

**4.2 PlanB Stock-to-Flow（S2F）模型（2019 走红 + 2022 失效）**

承自 PlanB 2019 Medium "Modeling Bitcoin Value with Scarcity" + LookIntoBitcoin + Francis Tapon 2019 反驳 + Yahoo Finance 2025 综述：

- **公式**：S2F = 流通量 / 年增量；PlanB 模型 P = exp(-1.84) × SF^3.36
- **2019 推出**：2020-05 减半前 S2F 模型预测"减半后 BTC 到 $55k-$100k"——基本命中（2021-11 顶部 $69k）
- **2020 S2FX 升级版**：PlanB 用 stock-to-flow cross asset model（S2FX）扩展到黄金 / 白银 / 其他资产
- **2022 LUNA 崩盘后模型失效**：BTC 跌到 $16k、模型预测 $100k+；LookIntoBitcoin 官方页面承认"predictive accuracy has weakened in recent years"
- **Francis Tapon 2019 反驳（"Plan B's Bitcoin stock-to-flow model will break in 2026"）**：列了 8 大缺陷——单变量、未考虑需求、未考虑监管、未考虑黑天鹅、未考虑 ETF、未考虑宏观、未考虑结构变化、未考虑减半后供应增量仍小
- **教训**：**单一静态公式无法捕捉动态系统**——这是《系统思维与反脆弱》§3 杠杆点的直接体现。S2F 是"密码朋克叙事的数学化"，不是"价格预测模型"。

**4.3 S2F 模型在项目中的正确用法**

- **不要用作价格预测工具**：已被实证否定
- **用作"叙事健康度"指标**：当 S2F 模型偏离实际价格 ±50% 时，市场叙事可能进入极端阶段
- **用作"叙事更替"信号**：S2F 失效 = "供应稀缺"叙事被"机构流入"叙事取代

### 第三部分　链上指标（必含）

#### 第六章　MVRV / MVRV Z-Score + SOPR + NUPL + Exchange Netflow

**6.1 MVRV（Market Value to Realized Value）**

承自 Glassnode Docs + LookIntoBitcoin + Coinglass：

- **公式**：MVRV = 市值（Market Cap）/ 实现价值（Realized Cap）
- **实现价值**：所有 UTXO 最后一次链上移动时的价格 × 数量
- **解读**：
  - MVRV > 3.5 = 顶部区域（全体持仓者浮盈 > 250%）
  - MVRV > 1.0 = 盈利态
  - MVRV < 1.0 = 亏损态（持有者集体浮亏）
  - MVRV < 0.7 = 深度底部区域
- **历史验证**：
  - 2013-11 MVRV ≈ 4 顶部（$1,217）
  - 2015-01 MVRV ≈ 0.7 底部（$152）
  - 2017-12 MVRV ≈ 3.7 顶部（$19,650）
  - 2018-12 MVRV ≈ 0.7 底部（$3,200）
  - 2021-11 MVRV ≈ 3.5 顶部（$69,000）
  - 2022-11 MVRV ≈ 0.95 底部（$15,500）
  - **2025-10 MVRV ≈ 2.29 顶部（$124,824）——历史上最低的顶部 MVRV**

**6.2 MVRV Z-Score**

承自 Glassnode Docs（MVRV-Z Score）+ LookIntoBitcoin：

- **公式**：Z = (市值 - 实现价值) / 市值的标准差
- **创建者**：Awe & Wonder（2018-10）
- **解读**：
  - Z > 7 = 强烈顶部信号（"红色区"）
  - Z > 3 = 顶部区域
  - Z = 0 = 平均水平
  - Z < 0 = 亏损态
  - Z < -0.5 = 深度底部（"绿色区"）
- **历史验证**：
  - 2013-11 Z ≈ 9-10 顶部
  - 2017-12 Z ≈ 10 顶部
  - 2021-04 / 2021-11 Z ≈ 7-8 顶部
  - 2025-10 Z ≈ 2-3（远低于历史顶部）——**Galaxy 2025 指出这是历史上最低的顶部 Z**
- **变种**：1-year rolling Z（Glassnode Week 02-2025 报告）更响应周期波动——传统的全历史 Z 已变得过于平滑

**6.3 SOPR（Spent Output Profit Ratio）+ aSOPR**

承自 Glassnode Docs（SOPR）+ MacroMicro + Bybit Wiki：

- **公式**：SOPR = 已花费 UTXO 的卖出价值 / 买入价值（加权平均）
- **解读**：
  - SOPR > 1.0 = 整体盈利兑现（多头在兑现浮盈）
  - SOPR = 1.0 = 盈亏平衡
  - SOPR < 1.0 = 整体亏损抛售
- **aSOPR（adjusted SOPR）**：剔除 1 小时以内交易后的版本——更稳健，更少噪音
- **实战信号**（Glassnode）：
  - 牛市顶部 = SOPR 持续 > 1.05 后快速跌破 1（顶部信号）
  - 熊市底部 = SOPR < 1 后回升 1（底部信号）
  - "SOPR Reset" = 暴跌后 SOPR < 1 然后回到 1 = 聪明钱抄底
- **局限**：短时间窗口（小时级）噪音大；推荐用 7d / 30d 移动平均

**6.4 NUPL（Net Unrealized Profit/Loss）**

承自 LookIntoBitcoin + Adamant Capital 2019 原文：

- **公式**：NUPL = (市值 - 实现价值) / 市值
- **5 个情绪阶段**（LookIntoBitcoin 颜色带）：
  - **Capitulation（投降）**：NUPL < 0（深度亏损）
  - **Hope / Fear（希望 / 恐惧）**：NUPL 0–0.25
  - **Optimism / Anxiety（乐观 / 焦虑）**：NUPL 0.25–0.5
  - **Belief / Denial（信念 / 否认）**：NUPL 0.5–0.75
  - **Euphoria / Greed（狂热 / 贪婪）**：NUPL > 0.75（顶部信号）
- **创建者**：Tamas Blummer + Tuur Demeester + Michiel Lescrauwaet（Adamant Capital, 2019-02）
- **实战**：
  - NUPL > 0.7 = 顶部区域（"狂热"阶段）
  - NUPL < 0 = 底部区域（"投降"阶段）
  - 2025-10 顶部 NUPL ≈ 0.55（"信念"阶段，远低于历史顶部的"狂热"）

**6.5 Exchange Netflow**

承自 CryptoQuant Exchange Flows 官方页面：

- **公式**：Netflow = Inflow（流入交易所）- Outflow（流出交易所）
- **解读**：
  - 正 Netflow（净流入）= 卖出压力（bearish signal）
  - 负 Netflow（净流出）= 持有/HODL 压力（bullish signal）
- **变种**：
  - **Total Netflow**：所有币种流入流出总和
  - **Top 10 Netflow**：最大的 10 笔交易（鲸鱼动向）
  - **Spot vs Derivative**：现货交易所 netflow 是方向信号，衍生品 netflow 是 OI 信号
- **实战**：
  - 持续负 Netflow（净流出）+ 价格上涨 = 强持有趋势
  - 突然正 Netflow（净流入）+ 价格顶部 = 鲸鱼抛售
  - "Whale wallet activity" 监控是顶部/底部的领先指标

**7.1 LTH / STH（Long-Term Holder / Short-Term Holder）**

承自 Glassnode Docs（LTH/STH Supply）+ LookIntoBitcoin + Bitbo：

- **实战信号**：

  - STH SOPR > 1.0 = 新钱在盈利（顶部信号——新钱接最后一棒）

**7.2 Puell Multiple**

承自 LookIntoBitcoin Puell + MacroMicro + David Puell 2019 Medium 原文：

- **公式**：Puell Multiple = 矿工日收入（USD）/ 矿工日收入 365 天移动平均
- **创建者**：David Puell（ARK Invest 分析师, 2019）
- **解读**：
  - Puell > 4 = 顶部区域（"矿工异常盈利 → 大规模抛售压力"）
  - Puell = 1 = 平均水平
  - Puell < 0.5 = 底部区域（"矿工收入低于历史 → 投降"）
- **历史验证**：
  - 2013-11 顶部 Puell ≈ 4-5
  - 2017-12 顶部 Puell ≈ 4-5
  - 2021-04 顶部 Puell ≈ 3.5
  - 2025-10 顶部 Puell < 3（远低于历史阈值）——**首次未达 4 阈值**
- **机制**：矿工收入高 → 矿工有动机抛售（卖币买矿机/付电费）→ 卖压增大 → 顶部；矿工收入低 → 矿工投降/关机 → 卖压消失 → 底部

**7.3 Pi Cycle Top Indicator**

承自 LookIntoBitcoin Pi Cycle + CoinMarketCap + NewHedge + arxiv 2607.26188：

- **公式**：111-day MA vs 350-day MA × 2 的交叉
- **创建者**：Philip Swift（LookIntoBitcoin, 2019-04）
- **历史准确度**（arxiv 2607.26188 实证）：
  - 2013-04 信号：HIT -3 天（信号前 3 天顶部）
  - 2013-12 信号：HIT +1 天
  - 2017-12 信号：HIT +0 天（精确到当天）
  - 2021-04 信号：HIT -1 天（2021-11 顶部未触发）
  - **2025-10 顶部：no fire（首次未触发）**
- **机制**：当 111d MA 上涨穿过 350d MA × 2 时，意味着"短期价格动量异常强于长期"——历史上每一次触发都对应顶部
- **2025-10 的"信号消失"**：Galaxy 2025 指出这是"4 年来 Pi Cycle 首次未触发"——但价格仍然按减半 +534 天节奏到达顶部

#### 第十三章　"减半必涨"的统计脆弱性 + 指标 vs 叙事优先级

**13.1 "减半必涨"是不是迷信？**

承自 arxiv 2607.26188 + crypto.news 2026 + BitcoinSuisse：

- **4 个数据点 = 统计推断薄弱**：n=4 不足以建立因果关系；可能只是巧合 + 选择性叙事
- **背后的经济学理由是真实的**：供应减半 → 需求不变 → 价格压力上升——这是"必要条件"，不是"充分条件"
- **理性解读**：减半构建了"供应紧张的边界条件"——但牛市还需要需求侧配合（ETF 流入 / 散户入场 / 监管友好 / 宏观放水）
- **2024-2025 是关键反例**：减半 + ETF 流入 + 宏观放水 = 涨；2025-10 后 ETF 流出 + 利率上升 + 顶部已现 = 跌——但按"减半 +12-18 月"应该在 2025-04 到 2025-10 顶部，实际是 2025-10-09 顶部（基本符合）

**13.2 "ETF 资金净流入必涨"——是真信号还是滞后指标？**

- **2024 验证了**（持续流入 + 价格涨）—— 但这是事后描述
- **2025 不一定**（流出时不一定跌）—— 2025-10 后 ETF 净流出时 BTC 跌 15%，但 2025-12 后又有反弹
- **流入/流出是滞后指标**：ETF 资金跟随机构决策，机构决策跟随基本面 + 宏观 + 情绪——ETF flow 是"结果"不是"原因"
- **实战用法**：ETF flow 是"机构情绪温度计"，不是"价格预测器"

**13.3 "MVRV > 3 是顶部"——历史 4 次成立 + 2025-10 反例**

- **2013-11 MVRV ≈ 4 顶部** → 历史成立
- **2017-12 MVRV ≈ 3.7 顶部** → 历史成立
- **2021-11 MVRV ≈ 3.5 顶部** → 历史成立
- **2024-12 / 2025-10 MVRV ≈ 2.29 顶部** → **首次未达 3 阈值**（历史反例）
- **教训**：单指标阈值不再可靠——MVRV 在 2025-10 顶部仅 2.29，但价格已 ATH
- **修正解读**：MVRV 反映"持币者浮盈率"，2025-10 顶部持币者浮盈率低是因为 ETF 引入了大量"高成本基础"新持币者——ETF 改变了 MVRV 的"代表性"

**13.4 指标 vs 叙事的优先级（实战原则）**

承自本文 §10 原则 + 《系统思维与反脆弱》§3 多杠杆点交叉验证：

| 决策维度 | 指标 | 叙事 |
| --- | --- | --- |
| **可量化** | ✓ 是 | ✗ 否 |
| **可机械触发** | ✓ 是 | ✗ 否 |
| **可事后验证** | ✓ 是 | ✓ 是 |
| **可事前预测** | ✗ 否（滞后 5-10 天） | 部分（领先但噪声大） |
| **2025-10 后有效性** | ✗ 哑火期 | ✓ 仍有效 |
| **实战优先级** | 第一（机械 trigger） | 第二（解释 + 校验） |

**决策纪律**：
- **指标 trigger + 叙事解释 + 决策 record**（三件套）
- **指标 vs 叙事冲突时**：以指标为准（数据更可靠），但记录叙事冲突作为"未来认知更新"
- **2025-10 后**：指标哑火期，叙事 + ETF flow + 宏观 + MSTR 持仓 4 维度交叉判断

**13.5 "Cross-Cycle Trading" 的真伪**

- **真**：减半供应规律 + 链上指标历史规律 + 叙事更替周期——这些是真实的、可观察的、可量化的
- **伪**："这次不一样 / 这次完全一样" 的过度简化判断——2025-10 后经典指标集体哑火，证明"机械套用历史规律"会失效
- **实战原则**：用历史规律做"先验概率"，用实时数据做"贝叶斯更新"——承自《如何用概率观看待和理解世界》§3

## 自测

1. **减半周期的 4 个数据点能建立因果关系吗？为什么？** —— 不能（n=4 统计推断薄弱），但背后经济学理由（供应减半 → 需求不变 → 价格压力上升）是合理的"必要条件"。承自 §13.1 + arxiv 2607.26188。

2. **2025-10 顶部为什么所有经典指标集体哑火？** —— ① ETF 引入了大量"高成本基础"新持币者改变了 MVRV 的代表性；② Pi Cycle 的"短期/长期均线偏离"被 ETF 平滑；③ Puell 在 ETF 时代"矿工收入占比"已经下降（机构资金量级 > 矿工）。承自 §5.2 + Galaxy 2025 + arxiv 2607.26188。

3. **MVRV / SOPR / Nupl / Puell / Pi Cycle / Exchange Netflow / LTH-STH 中，哪个最适合作为 Phase 1 费率套利的辅助告警？** —— **Exchange Netflow + Puell Multiple**——前者反映交易所抛压（直接影响费率套利的空腿风险），后者反映矿工抛压（影响整体资金费率）。MVRV / Nupl 是顶部/底部指标，对费率套利影响小。承自 §6.5 + §7.2。

4. **Phase 1 费率套利是否应该完全不看叙事/指标？** —— 不完全。① 必须看 Exchange Netflow（大额净流入 = 抛压 = 费率可能短期为负）；② 减半前后 6 月的费率异常（承自 §5.4）；③ 监管反转事件（如 USDT 在 EU 退市可能影响 Gate.io 上 USDT 计价）。其他叙事/指标可以缓看。

5. **如果 MVRV > 3.0 + Puell > 3.5 + Nupl > 0.65 + Pi Cycle 接近触发，应该做什么？** —— ① 进入"顶部警戒 mode"；② 日亏熔断从 -2% 收紧到 -1%；③ 仓位上限从 80% 降到 50%；④ 空腿保证金缓冲从 30% 提高到 50%；⑤ 飞书推送频次提升到每 4 小时一次；⑥ 复盘频率从周度提升到日度。承自 §12.2 + §14.2。

6. **设计一个 Phase 3 的"regime + 叙事 + 指标"4 维度交叉判据，要求至少 3 维度同时触发才进入"顶部警戒 mode"。** —— 维度 1：regime（HMM 给出 P(牛市) > 0.7）；维度 2：叙事日历（30 天内有重大事件 + 主流媒体亢奋度）；维度 3：链上指标（MVRV > 3.0 + Puell > 3.5 + Nupl > 0.65 任一）；维度 4：宏观 + 机构（ETF 单日净流入 > $500M 或 MSTR 单周买入 > $1B）。**任 3 维度同时触发 = 顶部警戒 mode**。承自 §10.3 + §14.2。

7. **为什么 PlanB S2F 模型在 2022 失效？这是技术问题还是叙事问题？** —— 双重失败。① **技术问题**：单变量 + 静态公式无法捕捉动态系统（Francis Tapon 8 大缺陷）；② **叙事问题**：2022 LUNA 崩盘后市场叙事从"供应稀缺"切换到"机构流入 + 监管反转"——S2F 是"密码朋克叙事的数学化"，叙事更替时模型必然失效。承自 §4.2 + §13.1 + 《系统思维与反脆弱》§3。

8. **MiCA 通过后，Tether（USDT）在 EU 退市，但 Gate.io 不受影响——为什么？** —— ① MiCA 是 EU 法规，Gate.io 注册在开曼 + 塞舌尔，不在 EU 管辖；② USDT 在 EU 退市是 EU 监管要求，但全球仍可流通；③ Gate.io 的合约交易以 USDT 计价，但现货 / 合约仍可用 USDT（仅限 EU 用户不能用法币买卖）；④ 长期看 EU 用户偏好 USDC / EURC。承自 §9.3。
