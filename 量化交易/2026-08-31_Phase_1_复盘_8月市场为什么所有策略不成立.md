## 可复用原则（决策时引用）

1. **环境选择 > 策略选择**：同一套策略（funding 套利 + BTC/ETH 统计套利）在 2024-09 减半后 17 个月 / 2025-10 顶部区 / 2026-08 减半后 28 个月三个时段的表现可以天差地别。**Phase 2 启动前先评估环境**，不是"环境选择策略"而是"环境否决策略"。承自《反脆弱决策清单》§F 重大金额交易"环境评估前置"。
2. **回测 negative result = valuable 信息，不 = 策略失败**：三关全负告诉我们的不是"费率套利不行 / 统计套利不行"，而是"2026-08 这个特定环境里不行"——这条信息比"再调参数"或"换策略"更有价值，因为它帮我们建立"环境-策略适配表"。**承自科学方法论：negative result 是可发表的研究结论，不是挫败**。
3. **协整 ≠ 盈利**：BTC/ETH 协整在 30 天样本上显著（ADF p=0.0193 + Johansen 系数稳定），但 8 月 BTC 走强（减半 +534 天节奏）让 ratio 单边上行——协整成立但回归路径不存在。**这是 pairs trading 的"统计学陷阱"**：协整是必要条件不是充分条件，均值回归的"回归速度"才是关键。承自《统计套利与 Pairs Trading》§6.3 结构性断裂 + §9.1 2020-03 案例。
4. **funding 太冷 = 盈亏平衡线以下必亏**：30 天平均 funding 0.004% 远低于往返成本 0.06%（0.04% 现货 taker + 0.01% 合约 taker + 0.02% spread cost + 0.01% 其他），盈亏平衡 = 0.005%/8h（来自《微观结构》§7.2）——8 月 funding 在盈亏平衡线以下运行 = **任何费率套利必亏**。承自《风险量化 VaR/CVaR/ES》§5 "找脆弱性" + 本文第二章。
5. **Cycle Flattening = "日历还在，指标哑火"**：2025-10 顶部所有经典指标集体失声（Pi Cycle/MVRV/Puell/Mayer 全部未触发），但价格仍按减半 +534 天节奏到达 $124,824（vs 2017/2021 的 525/546 天）。**含义**：不能依赖单指标判断顶部区域，必须 ETF flow + 减半日历 + 机构持仓 + 宏观 4 维度交叉。承自《加密叙事》§5.2 + §13.3 MVRV 反例。
6. **5 大纪律机制是反脆弱的工程方案，不是"道德规范"**：预承诺/标准化/对账/隔离/复盘——每个机制都有具体工程实现（L1 risk.yaml / L2 落库 / L4 对账 / L1 halt / 决策记录模板）。**纪律失效不一定是"违规"，可能是"环境让机制失效"**——8 月环境触发了 L1 的"行动偏差"机制失效（trader dry-run 部署不是为了开仓条件满足，而是为了"看看会怎样"）。
7. **100 USDT 项目 = 反偏差系统，不是赚钱机器**：Phase 1 三关全负的真正价值不是发现"哪个参数错了"，而是建立"**这种环境下不应该上线**"的纪律——这比月净收益 0.2 USDT 价值高 100 倍。承自《行为金融》§13.4 反偏差价值 > 赚钱价值。
8. **诚实声明是反脆弱的元方法**：本文明确"哪些是已知数据 / 哪些是假说 / 哪些是反例库必含"——把"挫败"变成"可发表的 negative result"需要先把"事实层"和"假说层"分开。承自《失败案例集》§4.5 Reinhart-Rogoff 反例 + §6.1 冗余 = 透明决策。

## 核心逻辑链

1. **前提**：三关回测（funding 套利 long / funding 套利 short / BTC-ETH 统计套利）在 2026-08（30 天 1h K线）全部 negative result：-0.72 USDT（0% 胜率 / 7 回合）/ 0 信号 / -6.29 USDT（42.9% 胜率 / 42 回合）。**用户 11 USDT 已充值 + trader dry-run 部署（3x 杠杆 + Gate 最小合约 BTC 0.0001/ETH 0.01 + 熔断 0.05 USDT）**。
2. **机制（环境特殊性）**：2026-08 = 2024-04 减半后第 28 个月（按历史规律在 25-30 月底部区）；8 月 BTC 走强但 classic 顶部指标哑火（2025-10 事件后）；ETF 主导结构性平移 4 年周期；30 天 funding 平均 0.004% 远低于 0.005%-0.01% 盈亏平衡线；BTC/ETH 协整虽成立（ADF p=0.0193）但 ratio 单边上行不回归。**5 个环境因素叠加** = 任何 delta 中性 + 统计套利策略在这一组合下都不成立。
3. **机制（策略根因）**：funding 套利 long = 0% 胜率因为 funding 转负次数过多（30 天 5 次）触发 L1 halt 单腿风险；funding 套利 short = 0 信号因为 funding 从未 ≤ -0.01%；BTC/ETH 协整 = ratio 单边上行触发高 z-score 开仓被止损/ETH leg 亏损抵消。**3 个策略各有具体技术原因，不是"市场不好"4 个字能解释的**。
4. **机制（行为纪律自检）**：5 大纪律机制哪些失效——预承诺（费率 ≥0.01% 开仓条件是预承诺但 trader dry-run 部署不是因为条件满足触发"行动偏差"）；标准化（统一 L1 risk.yaml 但 trader dry-run 是 11 USDT 单独资金触发"心理账户"）；对账（L2 + L4 正常运行）；隔离（L1 halt 因资金小未实际触发熔断）；复盘（本次复盘本身就是复盘机制在做）。**结论：机制覆盖到位但触发条件设定需要更严**——trader dry-run 部署应明确"仅在 funding ≥ 0.01% 持续 7 天后才部署"。
5. **结果（系统性学习）**：三关全负的真正价值是建立"环境-策略适配表"——funding 套利需要 funding ≥ 0.01%/8h 持续 7 天；统计套利需要 BTC/ETH ratio 不在单边趋势；BTC/ETH 协整需要半衰期 < 30 天。**Phase 2 启动条件 = 3 个环境信号同时满足 + 5 大纪律机制全部 trigger-ready**。
6. **行动指引**：① trader dry-run 立即暂停（资金 11 USDT 已熔断风险）；② P0-3 数据管道新增"环境信号"指标（funding 30 天均值 + BTC/ETH ratio 滚动回归 + 顶部指标 watch）；③ Phase 2 启动清单 = 环境三件套（funding/ratio/regime）+ 纪律五件套（预承诺/标准化/对账/隔离/复盘）+ L1-L6 七层架构全 ready；④ 3 周内（2026-09-21）再评估环境信号，不急重启；⑤ 把这次 negative result 作为"环境-策略适配"的反例库第一条记录。

#### 2.3 BTC/ETH 协整检验（30 天 1h 数据）

**OU 半衰期**：

### 第三章　三关全负的根因分析（每个策略具体为什么亏）

3. **深层原因**：Cycle Flattening 让 funding 结构性下降——ETF 主导让现货价格上涨慢，但永续市场仍有一定空头持仓，funding 在"临界"水平

#### 3.3 关 3：BTC/ETH 统计套利 -6.29 USDT（42 笔，42.9% 胜率）

- 入场：|z-score| > 2.0（基于 60h 滚动窗口）
- 出场：z-score 回到 ±0.5
- 止损：|z-score| > 3.5 OR 持仓时间 > 2 × 半衰期
- 协整向量：β = 0.842（来自 EG 两步法 + Johansen 验证）

**30 天 42 笔交易统计**：
- 胜率 42.9%（18 赢 / 24 亏）
- 平均盈利 = +0.18 USDT / 回合
- 平均亏损 = -0.35 USDT / 回合
- 盈亏比 = 0.51
- 最大单笔亏损 = -0.94 USDT（2026-08-15）

**42 笔分布**：
- 入场方向 short spread（卖 BTC 买 ETH）：16 笔，胜率 50%（8/16），平均 P&L = -0.08

**根因分析（5 层）**：

1. **表面原因**：BTC 走强 + ETH 跟不上 → ratio 单边上行 → 高 z-score 开仓（short spread 方向）后被止损 + ETH leg 亏损抵消
2. **直接原因**：OU 半衰期 42 天 > 工程可做区间边缘（5-60 天），均值回归速度慢 → 持仓时间 2 × 半衰期 = 84 天超过回测期
3. **深层原因**：BTC/ETH 协整在 8 月被 ETF 主导结构性破坏——BTC ETF 流入 5.75x ETH 让 ratio 单边（承自本文第二章 2.4）

5. **元原因**：回测用 closing price 成交 + 假设 spread 完全回归，实盘 mid + 滑点 + 实际回归慢 → 滑点 0.02% × 42 笔 × 2 leg = 1.68 USDT 隐性成本

**为什么 42.9% 胜率（接近随机但亏）**：
- 理论随机胜率 50%，实际 42.9% = 略低于随机
- 关键不是胜率而是**盈亏比 0.51**（小赢大亏）
- 即使胜率 60%，盈亏比 0.51 仍必亏（EV = 0.6 × 0.18 + 0.4 × (-0.35) = +0.108 - 0.140 = -0.032）

**对比历史回测（2024-09 至 2025-09）**：
- 同策略纸面胜率 56.4%
- 同周期 BTC/ETH ratio 月变化平均 ±1.8%（vs 2026-08 的 +2.4% 单边）
- 同周期 BTC/ETH 协整破裂次数 = 0（vs 2026-08 的 12 个窗口）
- **结论**：8 月协整结构被 ETF 主导破坏，不是参数问题

**关键教训（"协整 ≠ 盈利"的实证）**：
- ADF p=0.0193 显著 ≠ 8 月 ratio 单边时能盈利
- **静态协整检验通过 ≠ 动态回归路径稳定**
- 需要新增"滚动协整稳定性指数 CSI"作为入场前置条件（CSI > 0.05 → 不入场）

#### 7.2 行为偏差诊断（承自《行为金融》§11 + §12 + §13.2）

**主导偏差 = 行动偏差 + 过度自信 + 心理账户**（承自《行为金融》§13.1 Phase 0/1 偏差演化）：

**偏差 1：行动偏差**（Action Bias）
- **触发**："想先小资金试试"——部署 trader dry-run 时 funding 不满足条件
- **证据**：trader dry-run 部署时间 = 2026-08-01，funding 30 天均值 = 0.004% < 0.01% 阈值
- **影响**：关 1 + 关 2 + 关 3 全部在错误环境下运行
- **去偏工具**：架构初稿 L1 "halt 状态只接受平仓" + 本次复盘的"决策树 5 层 check"

**偏差 2：过度自信**（Overconfidence）
- **触发**：纸面回测胜率 78% → 实盘 0% 胜率（关 1）—— 纸面高估了策略表现
- **证据**：纸面用 closing price 成交 + 假设 funding 可预测，实盘 mid + 滑点 + funding 不可预测
- **影响**：决策者对策略的"确信度"超过实盘环境支持度
- **去偏工具**：校准训练（每条预测给百分比 + 事后核对分布）+ 5 关上强度检查（CPCV PBO/DSR）

**偏差 3：心理账户**（Mental Accounting）
- **触发**：11 USDT 单独资金 + trader dry-run 部署——和项目主资金池分开管理
- **证据**：trader dry-run 的熔断 0.05 USDT（占 11 USDT 的 0.45%）vs 架构初稿设计 -2% 熔断（占 11 USDT 的 0.22 USDT = 不合理配置）
- **影响**：用"小资金"心理账户规避了"全资金"风控规则
- **去偏工具**：单一资金池 + 单一 risk.yaml（架构初稿 L1 设计原则）

**偏差 4（潜在）：确认偏差**（Confirmation Bias）
- **触发**：纸面回测胜率高 → "策略没问题"的确认偏差
- **证据**：3 个策略都在 2024-09 至 2025-09 区间回测 = 牛市窗口（funding 旺 + ratio 回归），未在熊市/底部区验证
- **影响**：未做 regime-dependent 回测 → 实盘环境变化时策略失效
- **去偏工具**：多窗口回测（牛市/熊市/震荡分别回测）+ pre-mortem（想象 6 个月后失败）

## 自测

1. **（环境 vs 策略）** 解释为什么"环境选择 > 策略选择"是 Phase 2 启动的核心原则。8 月的 5 个环境因素（减半后期底部区 / 顶部哑火 / funding 太冷 / ratio 单边 / ETF 主导）如何具体让 3 个策略全部 negative result？给出每个策略的具体技术原因（不是"市场不好"4 个字）。

2. **（协整 ≠ 盈利）** BTC/ETH 协整在 30 天样本上显著（ADF p=0.0193 + Johansen 1 个协整向量），但 8 月 ratio 单边上行导致 -6.29 USDT 亏损。解释"静态协整成立但动态回归不发生"的具体机制。为什么 OU 半衰期 42 天（> 30 天工程边缘）让均值回归速度不够快？

3. **（funding 盈亏平衡线）** 8 月 funding 平均 0.0042% < 0.005% 盈亏平衡线。给出盈亏平衡线 0.005%/8h 的推导（往返成本 = 0.04% 现货 taker + 0.01% 合约 taker + 0.02% spread cost + 0.01% 其他 → 0.06%/12 = 0.005%/8h）。为什么 funding < 盈亏平衡线 = 任何费率套利必亏？

4. **（Cycle Flattening 的指标哑火期）** 2025-10 顶部所有经典指标集体失声（MVRV 2.29 / Puell 3.4 / Pi Cycle 未触发 / Mayer 1.78）。为什么"日历还在（减半 +534 天节奏）但指标已经哑火"？这对 Phase 2 启动的环境评估有什么含义（不能再依赖单指标）？

5. **（5 大纪律机制失效自检）** 8 月 5 大纪律机制中 3 个失效（预承诺/标准化/隔离）。每个失效的具体证据是什么？为什么说"机制覆盖到位但触发条件设定需要更严"？给出 trader dry-run 部署的修复方案（"仅在 funding ≥ 0.01% 持续 7 天后才部署"）。

6. **（决策树 5 层 check）** Phase 2 启动决策树有 5 层（环境信号三件套 / 纪律机制五件套 / L0-L6 七层架构 / trader dry-run 部署前 check / 实盘 90/10 杠铃）。为什么需要 5 层而不是 1 层？哪一层是"一票否决"的（任一不满足 → 不启动）？给出每层的具体阈值。
