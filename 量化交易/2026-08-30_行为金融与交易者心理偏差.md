## 可复用原则（决策时引用）

1. **市场不是对手，你大脑里的偏差才是对手**：散户/机构/专业交易者长期回报的差异（Barber-Odean 2001 男性户 -2.65%/年、女性 -1.72%/年）远超"聪明"或"勤奋"能解释——差距主要来自过度自信导致的过度交易。**先解决大脑，再谈策略**。
2. **偏差有"自动化能解决的"和"机制化才能解决的"两类**：认知偏差（过度自信 / 锚定 / 确认 / 可得性）能被自动化信号 + 规则消除；情感偏差（损失厌恶 / 后悔 / 沉没成本 / 心理账户）必须靠**预承诺 + 隔离 + 对账**等机制保护——"知道"在情绪激活时是无效的（承自《认知偏差全谱》§F/G）。
3. **马丁签名 = 平滑小赢曲线 + 罕见巨亏 = 100% 在卖隐性尾部保险**：（承自《自动量化加密货币的成功与失败》第十章）交易记录层面可数学识别的偏差信号（亏损后加仓 / 同向叠仓 / 单笔最大亏/平均盈利比异常），不需要打开策略黑盒。这是"行为偏差 → 实盘特征"的代码化检测。
4. **自动化消除 4 大偏差但会引入 1 大新风险**：消除行动偏差 / 后悔厌恶 / 心理账户 / 现状偏差；但**失去"现场感"会让极端行情的判断变慢**——所以自动化的边界要明确（什么场景自动、什么场景必须人工）。架构初稿 L1 禁止清单 #5"手动干预需二次确认"就是这个边界的实现。
5. **5 大纪律机制（预承诺 / 标准化 / 对账 / 隔离 / 复盘）是去偏的工程方案**：不是"靠意志力"，是把"我是否执行"从意志力问题变成系统问题。WHO 手术安全清单把死亡率从 1.5% 降到 0.8% 用的就是同款思路（承自《反脆弱决策清单》§3.3）。
6. **决策前 30 秒 + 决策中 5 分钟两套自检清单**：30 秒清单解决"启动偏差"（情绪 / 锚定 / 过度自信 / 沉没成本 / 框架），5 分钟清单解决"中段偏差"（叙事 / 确认 / 沉没 / 锚定 / 心理账户）。两套都是 5 个问题，5 分钟内能过完。
7. **偏差的"级联放大"是真正杀手**：单一偏差能扛，复合偏差常常归零（承自《认知偏差全谱》§3）。所以**单一去偏工具对复合偏差常常无效——必须用流程/清单/外部视角这类"系统级"对抗**。3AC/GBTC 套利（锚定"溢价不会消失" + 过度自信 + 处置效应反向 + 心理账户"已投了 12 亿"）就是这种级联的典型。
8. **100 USDT 项目的偏差演化有清晰节奏**：Phase 0 主要防过度自信（"100 USDT 也能大赚"幻觉）；Phase 1 主要防行动偏差（"98% 时间该观望"）；Phase 2 主要防确认偏差（"paper 数据显示好 ≠ 未来好"）。每个阶段的"主导偏差"不同，纪律机制也要相应切换。

## 核心逻辑链

1. **前提**：人脑是有限理性的预测机器（Simon 1955 bounded rationality）；在不确定 + 高情绪 + 信息过载场景下系统走捷径（heuristics）→ 偏差（承自《认知偏差全谱》§1）。EMH（Fama 1970）假设市场是理性的，行为金融（Thaler 1985 起）承认偏差与套利限制共同决定价格。
2. **机制一（行为金融 vs EMH 的核心争论）**：EMH = 价格反映所有信息，α 不可预测；行为金融 = α 来自可识别的偏差 + 套利限制（limits to arbitrage）；**两者实际是同一现象的两面**——Lo 2004 AMH 把它们融合为"效率随时间/制度/参与者结构演化的动态市场"。
3. **机制二（15+ 条偏差的"双坐标分类"）**：X 轴 = 认知偏差（可意识到 + 自动化能解）vs 情感偏差（难以意识到 + 机制化保护）；Y 轴 = 启发式（信息加工偏差）vs 偏好（价值评估偏差）vs 框架（决策情境偏差）vs 社会（群体影响）。每个偏差有自己的"主导象限 + 主导去偏工具"。
4. **机制三（偏差的"行为签名"）**：每个偏差在交易记录层面都有可数学识别的指纹——处置效应 = "盈利后 24h 平仓 / 亏损后 24h 持仓"；过度自信 = "换手率 70%+/年 + 收益负"；马丁签名 = "亏损后加仓 + 同向叠仓 + 单笔最大亏/平均盈利比 > 3"；等等。这是"行为偏差 → 量化检测"的桥。
5. **机制四（自动化的双刃剑）**：自动化消除认知偏差的执行干扰 + 情感偏差的现场激活，但**消除"现场感"**——让你在策略的"概念"和"实盘的真实风险"之间多了一层隔膜。架构初稿的"锁定模式 + 二次确认 + 异常熔断"是承认这个代价的工程方案。
6. **机制五（纪律机制 vs 流程机制）**：5 大纪律机制（预承诺/标准化/对账/隔离/复盘）= 流程级反偏差；2 套自检清单（决策前 30 秒 + 决策中 5 分钟）= 决策级反偏差；项目映射（Phase 0/1/2 偏差演化）= 阶段级反偏差。三层叠加 = 完整的反偏差系统。
7. **结果**：把"行为偏差"从"投资失败的模糊归因"变成"可识别、可诊断、可预防、可检测的工程问题"——这是行为金融给量化交易的最大礼物。
8. **行动指引**：① 在重要交易/策略调整前过 30 秒清单 → ② 决策中段（30-70% 投入时）过 5 分钟清单 → ③ 交易后用决策记录模板记下偏差自检 → ④ 季度复盘用 5 大纪律机制对照项目是否覆盖 → ⑤ 每年 1 次用马丁签名检测看自己/策略是否掉进隐性陷阱。
9. **诚实声明**：本文未直接读 Kahneman《Thinking, Fast and Slow》、Thaler《Nudge》、Taleb《Black Swan》、Fama 原作、Lo 2004 原文；所有数据/机制/案例均通过 Wikipedia 官方条目 + NBER/SSRN 论文摘要 + Investopedia/Farnam Street/Decision Lab/PMC PubMed 综述交叉验证。具体引用见文末"资料来源"。

## 分章笔记

### 第一部分　行为金融学框架

#### 第一章　EMH vs 行为金融（争议的本质）

**1.1 EMH 的核心主张（Fama 1970）**

Eugene Fama 1970 年在 *Journal of Finance* 正式提出"有效市场假说"（Efficient Market Hypothesis, EMH）——市场价格"充分反映"所有可获得的信息，资产收益在风险调整后**不可预测**。EMH 有三个版本：
- **弱式**：价格反映所有历史价格信息 → 技术分析无效
- **半强式**：价格反映所有公开信息 → 基本面分析无效
- **强式**：价格反映所有信息（含内幕）→ 内幕信息也无效

EMH 的隐含假设是**投资者是理性的**（即使个别非理性，套利会让价格回到基本面）。这一假设在 1970 年代被主流金融学奉为基石。

**1.2 行为金融的"反命题"（Thaler 1985 起）**

Richard Thaler 是行为金融学的主要奠基人。从 1980 年"Toward a Positive Theory of Consumer Choice"提出**禀赋效应**、1985 年"Mental Accounting and Consumer Choice"提出**心理账户**、1987 年正式命名"behavioral finance"——行为金融学用心理学证据**逐条反驳 EMH 的理性假设**：
- 投资者有可识别的偏差（损失厌恶 / 处置效应 / 过度自信 / 锚定等）
- 套利有**限制**（limits to arbitrage, Shleifer-Vishny 1997）——专业套利者无法消除非理性投资者的偏差
- 因此**价格可能在长时期内系统偏离基本面**（股票溢价之谜 / 动量 / 均值回归 / 处置效应等异常持续存在）

**1.3 Barberis-Thaler 2003 综述（NBER Working Paper No. 9222）**

Nicholas Barberis 和 Richard Thaler 2003 年在 *Handbook of the Economics of Finance* 发表"A Survey of Behavioral Finance"——这是行为金融学最权威的综述之一（SSRN 引用 26,000+）。核心论点：
- 行为金融 = 心理学 + 套利限制的双因子模型
- 偏差的"经济学表现"：单个投资者可能跑赢/跑输市场（运气），但**系统性的偏差模式在群体层面会让价格长期失真**
- 偏差的"实证证据"：股票溢价之谜（Benartzi-Thaler 1995）、动量（Jegadeesh-Titman 1993）、反转（De Bondt-Thaler 1985）、处置效应（Shefrin-Statman 1985）等都是"EMH 解释不了、行为金融能解释"的硬证据
- 行为金融**不否定市场是"基本有效的"**——它否定的是"完全有效"；实际市场是"大多数时候有效、有些时候系统性失真"

**1.4 争论的本质：EMH vs 行为金融不是"非此即彼"**

把两边推到极端都是错的。EMH 极端派（"市场永远有效，价格永远对"）忽视了偏差的实证证据；行为金融极端派（"市场总是错的，散户总能赢"）忽视了套利的力量。**真实市场是"效率在大多数时候 + 失真在某些时候"的混合**——这正是 AMH（第二章）要解决的。

#### 第二章　AMH（Adaptive Markets Hypothesis）作为融合框架

**2.1 Lo 2004 的进化论改造**

Andrew Lo 2004 年在 *Journal of Portfolio Management* 发表"The Adaptive Markets Hypothesis: Market Efficiency from an Evolutionary Perspective"——提出**自适应市场假说**（AMH），把 EMH 和行为金融融合：
- **市场效率不是静态的**，是随时间 + 制度 + 参与者结构 + 风险偏好**动态演化**的
- 投资者不是"理性 vs 非理性"二分，而是"**具有不同 heuristic 的异质 agent**"——在某种环境下某 heuristic 占优，另一种环境下另一种占优
- **套利的力量 = 进化选择**：在牛市里"追涨"的 heuristic 占优（因为短期被奖励），在熊市里"低吸"的 heuristic 占优（因为抄底被奖励）——**环境选择 agent，agent 改变环境**
- "alpha 会衰减"不是 bug，是 AMH 的预测——alpha 来自某种 heuristic 的暂时占优，被套利者学走后就衰减

**2.2 AMH 对交易者的启示**

- **不要追求"长期有效的 alpha"**——alpha 一定有衰减，问题是衰减速度和你的开发速度谁快
- **适应性比"最优化"更重要**——能在不同 regime 切换的策略比单一最优策略更持久
- **"市场是有效的"和"市场有偏差"是同一枚硬币的两面**——偏差是 alpha 的来源，套利是 alpha 的天花板
- **认知到 AMH 的人会做"反身性投资"**——不是预测"市场会怎么走"，而是预测"市场参与者会用哪种 heuristic"（承自 Soros 反身性思想）

**2.3 AMH 与本条的关联**

AMH 解释了为什么"行为偏差"既不被市场完全消除，也不让散户稳定赢——它是 markets 内生的、可演化的部分。对交易者的含义：
- **承认偏差会持续存在**（不是"知道就行"）
- **承认偏差会随时间变化**（不是"死记硬背"）
- **用"机制"而不是"知识"对抗偏差**（这是第三部分的核心）

#### 第三章　认知偏差 vs 情感偏差（可"意识到" vs 靠机制保护）

**3.1 两类偏差的本质区别**

行为金融把交易者偏差大致分为两类（这个二分法在 CFA 课程中广泛使用）：
- **认知偏差（Cognitive Biases）**：信息加工和处理时的失真——基于"thinking"，可被意识到，部分能通过训练缓解。包括过度自信 / 锚定 / 确认 / 可得性 / 代表性等。
- **情感偏差（Emotional Biases）**：价值评估和决策时的情绪驱动——基于"feeling"，难以被意识到，**必须靠机制保护**（不是知识）。包括损失厌恶 / 后悔 / 禀赋效应 / 过度乐观 / 过度反应等。

**3.2 自动化 vs 机制化**

| 偏差类型 | 典型例子 | 去偏工具 | 难度 |
| --- | --- | --- | --- |
| **认知偏差** | 过度自信、锚定、确认 | 自动化信号 + 规则 + 校准训练 | 中（"知道+训练"可缓解）|
| **情感偏差** | 损失厌恶、后悔、沉没成本 | 预承诺 + 隔离 + 心理账户统一 | 高（情绪激活时知识失效）|

**3.3 为什么"知道"不能解决情感偏差**

承自《认知偏差全谱》§5 反偏差策略和 G.I. Joe 谬误——**知道 ≠ 躲开**。情感偏差在情绪激活时**优先于理性思考**——大脑的边缘系统（limbic system，情绪中枢）比前额叶皮层（prefrontal cortex，理性中枢）快 5 万年进化。这意味着当你**正在亏损**时，即使你知道"不该加仓"，你的边缘系统也会主导决策。**机制保护（不能加仓的代码）比"知道不该加仓"更可靠**。

**3.4 对量化项目的含义**

行为金融告诉我们，**自动化策略的本质不是"更聪明"而是"更不容易被自己的大脑欺骗"**——这是为什么"反脆弱"原则里"机制化减法"（via negativa）比"聪明加法"更可靠。架构初稿 L1 禁止清单的 6 条全部对应某个情感偏差的反面（详见第十四章）。

### 第二部分　核心交易者偏差（17 条，必含）

每条格式：**定义 / 实证 / 触发场景 / 一句话反例 / 对应去偏工具**。

#### 第四章　6 条认知启发式偏差（Tversky-Kahneman 1974 + 拓展）

##### 4.1 过度自信 / Overconfidence

- **定义**：对自己答案/判断的确信度系统性高于真实准确率；是 1974 年以来最稳健的偏差之一（Hoffrage 2004 综述）。
- **实证**：Barber & Odean 2001 *QJE* "Boys will be Boys"——分析 35,000+ 户美国家庭 1991-1997 交易数据，**男性比女性交易多 45%、年化净收益少 1.4%**（单身男性更多 67%、少 2.3%）；Statman-Thorley-Vorkink 2006 证实"高换手率 + 低收益"的稳健关系；Singh et al. 2024 系统综述 137 项研究证实这是"最一致、最普遍、最广泛"的认知偏差之一。
- **触发**：仓位越集中越自信（"这只股票我研究过"）；3 笔连赚后觉得"自己悟了"；新策略回测夏普 3+ 立刻上实盘。
- **反例**：Hoffrage 2004——90% 自信的判断里 40% 是错的；过度自信的人不是"判断力更好"，是"高估自己的判断力"。
- **去偏工具**：校准训练（每条预测给百分比 + 事后核对分布）；确信度下校 1-2 档；把"我研究了 N 小时"换算成"我比市场多了什么独有信息"。

##### 4.2 处置效应 / Disposition Effect

- **定义**：过早卖出盈利头寸、过久持有亏损头寸（Shefrin & Statman 1985 *Journal of Finance*）。
- **实证**：Odean 1998 用 10,000+ 户美国家庭数据证实；中国（Feng-Seasholes 2005）、台湾（Barber-Lee-Odean 2007，85% 投资者卖出盈利快于亏损）、芬兰（Seru-Shumway-Stoffman 2010，成本 3.2-5.7%/年）、印度（印度散户）等多市场重复验证；Frazzini 2006 证实**专业基金经理也犯此偏差**（仅程度低些）。Seru 等 2010 估算"处置效应年化成本 3.2-5.7%"——这是交易者最贵的偏差之一。
- **机制**（Shefrin-Statman 原版 4 元素）：① 损失厌恶（prospect theory）+ ② 心理账户（按买入价独立账户化）+ ③ 后悔厌恶（不愿承认错误）+ ④ 自我控制（知道但改不了）。
- **反例**：机械止损线 = 不看盈亏符号按规则执行；预设止盈/止损位；用"今天从零开始，我会买/卖吗"问句代替"我已经赚/亏了"判断。
- **去偏工具**：自动化止损/止盈；Weber-Camerer 1995 实验证实"自动卖出（automatic）能大幅减少处置效应"；Fischbacher et al. 2017 证实"限价单"有类似效果——这都是"机制化反偏差"的硬证据。

##### 4.3 锚定效应 / Anchoring

- **定义**：决策严重依赖最先接收到的数字（即使该数字无关），后续调整不足（Tversky & Kahneman 1974 *Science*）。
- **实证**：Tversky-Kahneman 1974 转盘实验——非洲国家在联合国数量估计，轮盘转到 10 → 中位估计 25；转到 65 → 中位 45（调整不足的硬证据）；加密市场里买入价、历史最高价、IPO 估值、研报目标价都是锚。
- **触发**：股票历史最高价成为"心理价位"，即使公司基本面已变；分析师目标价成为个人判断的锚；新闻里的"开局价"成为仓位参考。
- **反例**：把"锚"单独写下来 + 找 2 个独立来源对比；问"如果我从不知道这个价格，我会买/卖吗"。
- **去偏工具**：决策时主动问"我刚才依赖的哪个数字是锚"；用同行业平均 PE/PB 替代单一公司的"过去高点"作参考。

##### 4.4 代表性启发式 / Representativeness

- **定义**：凭"像不像典型例子"判断概率，忽略基率（base rate）（Tversky-Kahneman 1974）。
- **实证**：Linda 问题（Tversky-Kahneman 1983）——人们高估"Linda 是银行出纳且积极参加女权运动"比"Linda 是银行出纳"概率更高（违反 P(A∩B) ≤ P(A)）；加密市场"以为这是下一个 Amazon"而忽略"1000 个故事里 9 个归零"的基率。
- **触发**：看好一只币因为"它像 2017 年的 ETH"；觉得某个团队靠谱因为"创始人像 Vitalk"；高估小样本代表性（3 个月回测就上线）。
- **反例**：先把基率问出来——"过去 1000 个这种叙事的项目，最终能跑出来的有几个？"
- **去偏工具**：参考类预测（Kahneman 推荐）；硬性要求每个新想法列 10 个类似过去案例的真实结果分布。

##### 4.5 可得性启发式 / Availability

- **定义**：凭"想得到多少例子"判断事件概率，例子越生动、越近期越多，被认为越可能（Tversky-Kahneman 1974）。
- **实证**：飞机失事新闻刷屏后高估飞行风险；2022 LUNA 崩盘后高估"算法稳定币会死"的概率；近期连续上涨就觉得"市场永远涨"。
- **触发**：加密群里刷屏的暴富故事；媒体反复报道的某类事件；最近 3 笔交易都赚就觉得"自己不会亏"。
- **反例**：新闻是事件过滤器，不是事件本身——查月度发生数 vs 媒体曝光数；冷启动 30 分钟后再做高情绪决策。
- **去偏工具**：刻意打开"对立信息源"10 分钟；用月度/年度数据代替"最近 3 次"。

##### 4.6 保守偏差 / Conservatism / 锚定调整不足

- **定义**：已有判断难以更新，面对新信息调整不足（与 4.3 锚定同源，Tversky-Kahneman 1974）。
- **实证**：股票分析师对盈利预测调整缓慢；交易者对"我错了"的信号反应迟钝。
- **触发**：套住的仓位"等等会反弹"；看好的标的"等等再涨"；一个证据出现时还坚持原有判断。
- **反例**：决策时主动写"我此刻的关键假设 + 如果哪个信号出现我就反悔"（WRAP 第 4 步 Prepare to be wrong，承自《决策记录模板》§8）。
- **去偏工具**：承诺触发器（commitment device）= 决策时同步写下"如果 X 信号出现我就重新评估"，让"我错"成为有准备的退出。

#### 第五章　4 条损失/心理账户偏差（Kahneman-Tversky 1979 + Thaler 1985）

##### 5.1 沉没成本谬误 / Sunk Cost Fallacy

- **定义**：已经花掉的、不可收回的成本，被纳入"该不该继续"的考量——但理性决策不该考虑它（Thaler 1980；Kahneman-Tversky 1979）。
- **实证**：Arkes-Blumer 1985 经典实验——"已经买票了"的人更倾向看难看电影；加密里"已经亏了这么多不能走"的死扛行为。
- **触发**：项目亏了 10 万，因为"已经亏了"继续投入；合约到期前不退出因为"已经投了这么久"。
- **反例**：每笔投入只问"如果今天从零开始，我会重新投这笔吗"，不再问"我已经投了多少"（承自《认知偏差全谱》D 组 #21）。
- **去偏工具**：决策记录模板 §5 字段 5"如果从零开始"问句；架构初稿 L1 禁止清单把"亏损后加仓"识别为马丁签名（详见第十章）。

##### 5.2 损失厌恶 / Loss Aversion

- **定义**：亏损带来的痛苦 ≈ 同等金额盈利带来快乐的 2 倍（Kahneman-Tversky 1979 *Econometrica* 的 prospect theory 核心发现）。
- **实证**：原始实验中"亏 100 的痛 ≈ 赚 200 的乐"——损失曲线的斜率是盈利曲线的 2 倍；Thaler 1980 把它推广到经济学；2017 年 Thaler 凭此领域贡献获诺贝尔经济学奖。
- **触发**：浮盈 1000 提前止盈，浮亏 1000 死扛不止损——同一阈值反向行为；不愿卖出亏损仓位；亏了之后报复性加仓。
- **反例**：机械止损线，不看浮盈浮亏，按规则执行；用"我此刻情绪状态"自检避免"亏后立即决策"。
- **去偏工具**：预设止损/止盈；预承诺（commitment device）；架构初稿 L1 "halt 状态只接受平仓指令"就是损失厌恶的工程化反制。

##### 5.3 心理账户 / Mental Accounting

- **定义：把钱按主观分类（"工资"/"奖金"/"意外之财"）分别对待，导致不一致的风险偏好（Thaler 1985 *Marketing Science*；Hastings-Shapiro 2013 实证"汽油降价时从普通到高端的转换量是标准需求模型的 14 倍"）。
- **实证**：Thaler 1985 "Mental Accounting and Consumer Choice"——人们把消费分成不同账户（住房/食品/衣物），每个账户有独立预算和独立参考点，导致**有限可替代性**（limited fungibility）；Thaler-Sunstein 2008 指出"同时有储蓄账户和信用卡债务"是心理账户的非理性表现（高息债务 + 低息储蓄并存）。
- **触发**：博彩赢来的钱更大胆（"反正白来的"）；同样的 1 万块，"攒的工资"不舍得亏，"捡来的"随便赌；项目里"测试本金"和"实盘本金"用不同风险偏好管理。
- **反例**：建立"统一账户"思维——所有资金同风险偏好管理，不分来源；100 USDT 项目"单一资金池，单一 risk.yaml"就是反心理账户的工程方案。
- **去偏工具**：把多账户合并为统一账户（架构初稿 L1 risk.yaml 单一配置源）；交易前问"如果这是同一笔钱，我还会做这个决策吗"。

##### 5.4 后见之明偏差 / Hindsight Bias（"我早就知道了"效应）

- **定义**：事后觉得事先发生的事是可预测的、早就看得出来的（Fischhoff 1975 首次实验证实；2025 年 PubMed 综述"Fifty Years of Hindsight Bias Research"纪念原文发表 50 周年）。
- **实证**：Roese-Vohs 2012 综述确认三层次：① mismemory（记错了自己当时的想法）→ ② inevitability（觉得"这事注定发生"）→ ③ foreseeability（觉得"我能预见"）；PubMed 39913490 综述：后见之明是过度自信的"主要来源"之一（Barberis-Thaler 2003 假说，2024 实证证实）。
- **触发**：每次暴跌后都说"早该跑"——但事前完全没预测到；用它来评价自己和他人的预测准确度；"我 2018 年就说过 BTC 会到 10 万"——但 2018 年实际说的是"会回调到 3000"。
- **反例**：把预测记录写下来；评价分析师时只看他事先说的话，不看事后解释；每个决策归档（承自《决策记录模板》）。
- **去偏工具**：决策记录强制把"事前判断"和"事后解释"分开；月度量化的"事前 vs 事后"校准。

#### 第六章　6 条高级偏差（确认 / 注意力 / 行动 / 不动 / 叙事 / 羊群）

##### 6.1 确认偏差 / Confirmation Bias

- **定义：主动寻找、记忆、解读与自己已有观点一致的信息，忽略反面证据（Nickerson 1998 *Review of General Psychology* 系统综述）。
- **实证**：Nickerson 1998 综述 30+ 项研究证实——"几乎所有认知任务中都存在确认偏差"；加密市场里"看好某币就只看利好新闻，回避利空"；Karki-Bhatia-Sharma 2024 综述：交易者"在信息丰富环境（如在线交易平台）下确认偏差更明显"，导致资产错误定价。
- **触发**：看好一只股票，只看利好新闻，回避利空；选医生只看支持草药疗法的研究；KOL 让你看好一个项目你就找支持证据。
- **反例**：在做决定前**专门花 30 分钟找反面证据**——不是反着看，是正着找"我可能错在哪"；订阅"对家观点"的内容源。
- **去偏工具**：**对立面思考**（写"为什么我可能是错的"的清单至少 3 条）；pre-mortem（想象 6 个月后失败，强制想反向证据，承自《反脆弱决策清单》§5.1）；"魔鬼代言人"角色。

##### 6.2 注意力偏差 / Attention Bias

- **定义**：只关注与当前目标/威胁相关的刺激，无视其他信号。
- **触发**：监控面板上"红色警示"之外的次要数据被忽略；交易只盯着价格不看持仓/资金费率；看到涨的板块就追，忽略跌的板块。
- **反例**：架构初稿 L6 监控层把"关键指标"主动推到飞书（资金费率 / 保证金使用率 / 订单超时），不让注意力漂移；1986 挑战者号教训——工程师的 O 形环警告被发射日程紧迫感过滤。
- **去偏工具**：把"必须看的指标"列表化（L6 告警清单）；dashboard 减法 > 加法（不加新指标，而把已有指标减到关键 5-7 个）。

##### 6.3 行动偏差 / Action Bias

- **定义：不交易就焦虑 → 频繁交易；"做点什么"比"什么都不做"更让大脑舒服。
- **实证**：Barber-Odean 2001 证实高换手率（70%+/年）显著负向影响收益；NBER 综述把"过度交易"列为过度自信最直接的实证表现。
- **触发**：FOMO 追涨；觉得"今天没下单就亏了"；FOMC 前 24h 频繁开平仓；"98% 时间该观望"但忍不住要动手。
- **反例**：问"如果今天什么都不做，我会更遗憾还是更开心"——大多数时候答案是"不操作"；把"行动"和"收益"解耦，明确"持有也是仓位"。
- **去偏工具**：架构初稿 L1 "halt 状态只接受平仓"——把"想动手"挡在系统外；明确的"非交易时段"纪律（每天 2 小时看一次盘而不是每分钟）。

##### 6.4 不动偏差 / Status Quo Bias

- **定义：偏好"维持现状"远高于理性评估所支持的（Samuelson-Zeckhauser 1988 *Journal of Risk and Uncertainty*）。
- **实证**：Kahneman-Knetsch-Thaler 1991 *Journal of Economic Perspectives* 证实——雇主默认加入 401k 计划参与率 90% vs 手动加入 50%；健康保险默认选项的参与率 70% vs 20%。
- **触发**：套住了就装作没看见；"再等等更好的退出价"；策略明明不行但继续跑（因为"我正在跑"）。
- **反例**：把"如果我现在是新投资人，我会买/卖吗"作为每个持仓的问句（承自《认知偏差全谱》D 组 #24）。
- **去偏工具**：每月 1 日把持仓截图存档并对比——3 个月、6 个月、1 年的"漂移"一目了然。

##### 6.5 叙事谬误 / Narrative Fallacy

- **定义：人会为随机事件编造连贯的因果故事，然后把这些故事当作预测依据（Taleb 2010 *Black Swan* 第十章）。
- **实证**：Taleb 用 1987 黑色星期一的"解释"举例——事后来看总有"故事"，但事前这些故事没有一个能预测；Fischhoff 1975 后见之明偏差是叙事谬误的认知基础。
- **触发**："这次暴跌是因为 X"——实际是无数微小因素叠加；"这家公司会成为下一个 XX"——基于漂亮的叙述而非数字；3AC 的 GBTC 套利"故事"让所有人忽略"溢价会消失"的可能性。
- **反例**：每个故事配一张数字表（基率、历史相似情境下的实际表现），故事说完让数字先发言。
- **去偏工具**：参考类预测（reference class forecasting）——找 10 个类似项目/交易，看它们的真实结果分布；用中位数而不是平均值。

##### 6.6 羊群效应 / Herding（金融版）

- **定义：在投资/交易中跟随多数人行动，哪怕自己的信息指向相反结论（Banerjee 1992 AER 经典模型；Shah-Zhang-Zhang 2019 实证 herding 在熊市更强）。
- **实证**：Shah et al. 2019 证实 2008-2017 金融危机期间投资者和管理者 herding bias 都显著；COVID 期间 herding 在新兴市场最明显（Bogdan et al. 2022）。
- **触发**：FOMO 追涨；热门币全仓；"机构都在买"作为理由；看到群里刷屏就跟着买。
- **反例**：当你想跟进，先想"如果我只有这个标的、不知道别人怎么做，我会买吗"（承自《认知偏差全谱》H 组 #47）。
- **去偏工具**：主动列出"如果不跟会怎样"——"反着跟"也是 1 个方向，"不跟"也是 1 个方向。

#### 第七章　3 条反射/禀赋偏差（Bell 1982 + Thaler 1980）

##### 7.1 后悔厌恶 / Regret Aversion

- **定义：怕"做错了后悔"而不敢做（Bell 1982 首次提出；Loomes-Sugden 1982 发展）。
- **实证**：Shah-Malik 2021 *Humanities & Social Sciences Reviews* 证实：后悔厌恶 + 损失厌恶对个人投资者交易频率有显著负向影响；Farhana-Jannatul 2023 实证后悔厌恶是影响投资决策的最关键心理因素之一（巴基斯坦、印度、马来西亚、土耳其多市场验证）。
- **触发**：空仓时不敢买入（怕买了就跌 → 后悔）；满仓时不敢卖出（怕卖了就涨 → 后悔）；"如果当时……"的反复回想。
- **反例**：决策时同步写下"WRAP 第 4 步 Prepare to be wrong"——把"我错"从"事后被打脸"变成"事前已准备好的退出条件"。
- **去偏工具**：决策记录模板 §8 承诺字段（"如果 X 信号出现，我承诺 [具体动作]"）——把"我可能会错"前置到决策时，减少事后后悔的情绪冲击。

##### 7.2 风险反射效应 / Reflection Effect

- **定义：盈利时风险厌恶，亏损时风险寻求（Kahneman-Tversky 1979 prospect theory 价值函数 S 形）。
- **实证**：实验经济学大量重复——抛硬币赌 100 元，盈利 50 时多数人选择"锁定盈利不赌"（风险厌恶），亏损 50 时多数人选择"赌一把回本"（风险寻求）；Thaler-Johnson 1990"break-even effect"——亏损时倾向加倍下注。
- **触发**：浮盈 5% 落袋为安（明明可以等 10%），浮亏 30% 反向加仓（"再扛一扛就回本"）；亏损后报复性交易。
- **反例**：同一阈值反向行为——浮盈 5% 和浮亏 5% 用同一规则；不让"亏损"激活"加大赌注"的反射。
- **去偏工具**：架构初稿 L1 "halt 状态只接受平仓" + "马丁签名检测"——亏损后任何加仓动作都需要独立检查（不能简单追加）。

##### 7.3 现状偏好 + 禀赋效应 / Status Quo Bias + Endowment Effect

- **定义：拥有的东西估值显著高于愿意为它付的价格（Thaler 1980）；"现状"被视为"参考点"，偏离被视为损失。
- **实证**：Kahneman-Knetsch-Thaler 1991 *Journal of Economic Perspectives* "Anomalies" 经典论文——咖啡杯/钢笔的 WTA（愿意接受）/ WTP（愿意付）比例的几何平均是 3.28（即卖出价是买入价的 3.28 倍）；Plott-Zeiler 2005 *AER* 警示：早期禀赋效应实验可能有"误解"成分，但**WTA/WTP 不对称在多次复现中稳健**。
- **触发**：不愿卖出自有房产（即使市场价更高）；持仓"舍不得卖"因为"已经拥有了"；离职时对公司股票/福利估价畸高。
- **反例**：做"换边思考"——"如果我没有这个东西，市场价多少我愿意买？"答案通常低很多。
- **去偏工具**：决策时问"如果我从没拥有过，今天买入的话我愿意出什么价"——用"反向交易者"视角重新评估。

### 第三部分　交易纪律的反向设计（必含）

#### 第八章　为什么"自动化"是行为偏差的最佳解药

**8.1 自动化消除的 4 大偏差**

- **行动偏差** → 自动化信号驱动，无"做点什么"焦虑
- **后悔厌恶** → 机器执行，无"我当时……"的反复回想
- **心理账户** → 统一账户思维（架构初稿 L1 risk.yaml 单一配置源）
- **现状偏好** → 自动 rebalance，不让"已持有的"影响判断

**8.2 自动化消除不了但能保护的偏差**

- **损失厌恶** → 机械止损线（不让"亏损"激活加仓反射）
- **处置效应** → 预设止盈/止损位（不看盈亏符号按规则执行）
- **沉没成本** → 决策记录模板 §5 字段 5（"如果从零开始"问句前置到决策时）
- **过度自信** → 校准训练 + 季度复盘（事后核对预测准确率）

**8.3 自动化引入的 1 大新风险：失去"现场感"**

自动化消除了执行干扰，但**也消除了"现场感"**——让你在策略的"概念"和"实盘的真实风险"之间多了一层隔膜：
- 极端行情下你的反应速度 = 代码执行速度，但代码可能没考虑过这种 regime
- 你的"直觉"被算法取代，但算法的设计者（你/团队）也是人，也有偏差
- 自动化让"决策质量"问题从"每次决策"变成"策略设计"——后者的偏差更难发现

**8.4 自动化的边界（架构初稿的设计）**

什么场景必须自动、什么场景必须人工：
- **必须自动**：常规信号 → 订单执行；风控检查；熔断触发；对账
- **必须人工**：策略首次上线；参数重大调整；超过 30% 资金再分配；架构级修改
- **半自动（带二次确认）**：手动改仓；异常处理；交易所维护期应对（承自架构初稿 L6 + L1 禁止清单 #5）

#### 第九章　5 大纪律机制（预承诺 / 标准化 / 对账 / 隔离 / 复盘）

**9.1 预承诺（pre-commitment）**

- **机制**：决策时同步把"如果 X 出现，我就做 Y"作为规则写入代码——把"我会不会反悔"从意志力问题变成系统问题。
- **架构初稿对应**：risk.yaml 的所有硬限制参数（杠杆 1x / 日亏 -2% / 回撤 -10% / 费率转负清仓）；L1 禁止清单的 6 条；L6 监控告警的触发逻辑。
- **反例**：把规则写在文档里而不是代码里 → "我可以选择不遵守"。

**9.2 标准化（standardization）**

- **机制**：同一策略用统一信号、统一执行；不同策略走相同风控；任何"特殊处理"需要人工显式批准。
- **架构初稿对应**：所有策略共用 L1 风控配置；CCXT + 自研风控；统一告警通道（飞书）。
- **反例**：策略 A 用 1x 杠杆，策略 B 用 2x（"因为策略 B 是大币"）—— 永远是规则例外。

**9.3 对账（reconciliation）**

- **机制**：本地 vs 交易所定期对账；SQLite 持久化 + 状态恢复 + 差异告警。
- **架构初稿对应**：L2 数据层（CCXT + 落库）；L4 执行层"幂等 + 对账再继续"；L6 "对账差异"告警。
- **反例**：本地记录"我有 1 BTC"但交易所实际 0.5 BTC——爆仓了才发现。

**9.4 隔离（isolation）**

- **机制**：自动 vs 手动操作严格分开；策略运行中的人工改仓需二次确认 + 记录日志。
- **架构初稿对应**：L1 禁止清单 #5"手动干预后门"需二次确认 + 记录；锁定模式（lock mode）防止情绪化操作。
- **反例**：V2EX 案例——A 股小市值量化 1 年亏 20,538 元（-20.75%），其中人工干预亏 8,000+（占 40%）——隔离缺失的代价。

**9.5 复盘（review）**

- **机制**：日度自动日志 + 每周人工复盘 30 分钟 + 每月深度复盘 + 每季度贝叶斯更新。
- **架构初稿对应**：L6 监控层"日度汇总报告"；承自《决策记录模板》§5.1 1 周/1 月/3 月/1 年复盘节奏。
- **反例**：只看日报的 PnL，不看交易记录、偏差自检、参数漂移——复盘变成"看数字"。

**9.6 为什么 5 大纪律机制能"去偏"**

承自《反脆弱决策清单》§3.3 + WHO 手术安全清单证据——**清单把"我应该记得却忘了"的成本降到最低**。决策科学的反复证据：结构化流程 > 个人自律；流程级反偏差 > 知识级反偏差；机器执行 > 人脑执行（在偏差场景下）。

#### 第十章　马丁签名检测（自动识别"高胜率 + 罕见巨亏"）

**10.1 马丁签名的数学特征**

承自《自动量化加密货币的成功与失败》第十章 + Reddit / GitHub 公开策略复盘：
- **亏损后加仓**（同一标的连续亏损时下一笔仓位 > 上一笔）
- **同向叠仓**（多个仓位同向暴露，不是分散）
- **单笔最大亏 / 平均盈利 > 3**（罕见巨亏是平滑小赢的代价）
- **夏普 3+ 但最大回撤 > 30%**（回测好看但实盘脆弱）
- **胜率 > 70% 但盈亏比 < 0.5**（高胜率策略的典型马丁特征）

**10.2 为什么要自动检测**

手动看交易记录判断"是不是马丁"是认知偏差重灾区——处置效应让你对盈利"满意"、对亏损"忽略"；后见之明让你觉得"亏损是例外"。**代码化的马丁签名检测不依赖于人的判断**：
- 每次成交记录自动入库（盈亏符号 / 仓位大小 / 持仓时长 / 同向敞口）
- 每月/每周自动跑"马丁签名检测算法"——4 个数学条件都满足则告警
- 告警触发 → L1 风控层进入 halt 状态 → 只接受平仓 → 人工 review 后才能继续

**10.3 架构初稿的对应**

架构初稿 L1 禁止清单的 `martingale_like_patterns` 字段 + L3 研究回测层的"马丁签名检测"是这一章的代码化实现。

**10.4 警示：马丁签名 ≠ 永远禁用**

马丁签名是"卖出尾部保险"——在均值回归标的上（如商品）可能有利可图（Locke-Mann 2005 证实专业交易者在 commodity 上保留处置效应是理性的，因为 commodity 是 mean-reverting）；但**在加密永续这种 non-mean-reverting 标的上是致命**。所以马丁签名的告警应该**配合标的类型**（BTC/ETH 大币 vs 小币 vs 商品）做差异化判断。

### 第四部分　偏差自我诊断（必含）

#### 第十一章　决策前 30 秒自检（5 条核心问题）

承自《认知偏差全谱》§4 决策前 12 问句 + 《反脆弱决策清单》§3.1 投资领域 11 条。**任何重要交易/策略调整前 30 秒过一遍**：

| # | 暂停问题 | 对应偏差 | 一句话反例 |
| --- | --- | --- | --- |
| **Q1** | 我此刻最想做的动作是什么？ | 行动偏差 / 后悔厌恶 | 强烈的"想动手"情绪 → 大概率是被行动偏差激活 |
| **Q2** | 如果我今天什么都没做，我会更遗憾还是更开心？ | 行动偏差 vs 不动偏差 | "更开心" → 真的该不动；"更遗憾" → 检查是不是"应该的遗憾"还是"FOMO" |
| **Q3** | 我对这个决策的自信度是 90% 还是 95%？如果是 95%，降回 80% | 过度自信 | 95% 自信的判断里 50%+ 是错的（Hoffrage 2004） |
| **Q4** | 如果这是朋友的决策，我会劝他做吗？ | 框架 / 心理账户 | "会劝他做" → 真的合理；"不会" → 自己被框架/账户污染了 |
| **Q5** | 这个决策是否在"状态依赖"——比如刚亏损/刚盈利后？ | 损失反射 / 风险反射 | 刚亏后想加仓 = 风险反射；刚赚后想加仓 = 过度自信 |

**5 条全过完 = 30 秒，足够覆盖最常见的 5 大启动偏差**。

#### 第十二章　决策中 5 分钟暂停（5 条问句）

决策进行到 30-70% 时（已投入一些但还没彻底锁定），按下面 5 步暂停 5 分钟。承自《反脆弱决策清单》§4 决策中校验清单的展开：

| # | 暂停问题 | 对应偏差 | 一句话反例 |
| --- | --- | --- | --- |
| **P1** | 我是否在做"非线性"反应——把账户里其他钱的心理账户算到这一笔？ | 心理账户 | "其他币亏了，这笔必须赚回来" → 心理账户跨账户污染 |
| **P2** | 我是否在"叙事"里——把无序事件讲成因果？ | 叙事谬误 | "因为 X 所以 Y 所以 Z" → 故事很顺但没有数字支持 |
| **P3** | 我是否在找"确认"——只听支持我观点的论据？ | 确认偏差 | 30 分钟没找到反面证据 → 大概率没在找 |
| **P4** | 我是否在"沉没成本"里——"已经亏了这么多不能走"？ | 沉没成本 | "如果从零开始，我会重新投这笔吗？"——答案是"不会" → 该撤 |
| **P5** | 我是否在"锚定"里——以买入价 / 历史高点做参考？ | 锚定 | "成本价是 100，现在 80 不能卖" → 价格本身和质量无关 |

**特别触发器（满足任一立刻停下）**：
- 任何"等等再想"的瞬间 → 立刻想
- 任何"应该没问题"的瞬间 → 正是问题最大处
- 任何"再追加一点就能翻盘"的瞬间 → 凹性暴露的标准剧本
- 任何"别人都在做"的瞬间 → 羊群效应 + 反向思考

### 第五部分　项目应用映射（必含）

#### 第十三章　100 USDT 自动量化项目的偏差演化（Phase 0/1/2）

每个阶段都有"主导偏差"——纪律机制要相应切换。

**13.1 Phase 0（风控 + 数据 + 监控，主导偏差 = 过度自信）**

- **典型场景**：用户用 100 USDT 上量化项目，第一天就问"什么时候能赚到 1000 USDT"
- **主导偏差**：**过度自信**——"100 USDT 也能大赚"幻觉；可能伴随"行动偏差"（想在 paper trading 之前先小资金试试）
- **反制机制**：
  - L1 风控先于一切（"先不败再求胜"——架构初稿设计原则 1）
  - 2 周费率观测期（不允许开仓——主动制造"等待"以防行动偏差）
  - 项目"预期月净收益 0.2-0.5 USDT"明确写入文档（校正过度自信）
  - 用户 80% 手续费返点 + 100 USDT 本金 → 月真实净收益约 0.18-0.4 USDT（避免"过度自信"放大到不可持续规模）
- **承自**：架构初稿 L1 禁止清单 + Phase 0 任务清单 P0-1 到 P0-5

**13.2 Phase 1（费率套利回测 + paper trading，主导偏差 = 行动偏差）**

- **典型场景**：paper trading 2 周无成交 → 焦虑 → 想"先小资金试试"
- **主导偏差**：**行动偏差**——"98% 时间该观望"但忍不住要动手；同时"乐观偏差"——paper 数据显示好就觉得实盘也会好
- **反制机制**：
  - 30 天平均费率 ≥ 0.01%/8h 的开仓条件（不让"开仓"动作随意触发）
  - 决策记录模板的"11 字段 + 1 周/1 月/3 月/1 年复盘"——把"为什么不动"也记录下来
  - pre-mortem：想象 6 个月后失败的原因，强制反向证据
  - L6 飞书告警：长期无成交也要推送（让"不动"成为可见的、被记录的"主动决策"）
- **承自**：架构初稿 L5 策略层 + 决策记录模板 §5.1 复盘节奏

**13.3 Phase 2（小资金实盘，主导偏差 = 确认偏差）**

- **典型场景**：paper 数据显示好 → 上实盘 → 几次连亏 → 怀疑策略 → 改参数 → 改坏了
- **主导偏差**：**确认偏差**——paper 数据显示好就选择性记忆好消息；同时"行动偏差"（想"再调一下"）+ "沉没成本"（"已经投了这么多不能停"）
- **反制机制**：
  - L3 研究回测层"5 关上强度检查"（承自《回测方法论深化与CPCV》§7.2）——任一关 FAIL 不准进入 paper trading
  - 4-8 周小资金实盘期，日度复盘 + 偏差自检
  - L1 熔断线：日亏 -2% 当日停机 / 回撤 -10% 全停人工复盘（机制化反"沉没成本"）
  - 锁定模式（lock mode）：小资金期不允许人工改仓（防 V2EX 案例的人工干预亏 40%）
- **承自**：架构初稿 L3 5 关上强度 + L1 熔断 + L6 锁定模式

**13.4 关键洞察：100 USDT 项目的"反偏差"价值大于"赚钱"价值**

承自《系统思维与反脆弱》§3 第 6 级杠杆（信息流向 = 杠杆）+ §10.7 "目标是让游戏继续"——100 USDT 项目的真正意义不是月净收益 0.2-0.5 USDT，而是**建立"反偏差系统"作为可选择性资产**：
- 如果这套系统在 100 USDT 上跑通了，将来 5,000 USDT 也能跑通
- 如果发现偏差系统在某些场景失效（比如极端行情），现在改的成本是 100 USDT，将来改的成本是 5,000 USDT
- 偏差系统的"小压力测试"价值 > 月净收益 0.2 USDT（反脆弱原则的"小剂量可控压力"应用）

#### 第十四章　架构初稿 L1/L5/L6 的偏差对应

**14.1 L1 禁止清单 = 偏差的"反面"**

| 禁止清单条目 | 对应的偏差 | 反制机制 |
| --- | --- | --- |
| 1. 禁高杠杆方向单（>2x） | 过度自信 + 风险反射 | 杠杆上限代码化 |
| 2. 禁网格/马丁裸跑 | 过度自信 + 行动偏差 | 区间外失效硬逻辑 |
| 3. 禁用动量逻辑交易小币 | 代表性偏差 + 可得性偏差 | 币种白名单（top 2% 市值）|
| 4. 禁单一交易所集中 | 现状偏好 + 沉没成本 | 资产跨所分散 |
| 5. 禁"手动干预后门" | 后悔厌恶 + 行动偏差 | 二次确认 + 记录日志 |
| 6. 资金费率转负 → 自动清仓 | 损失反射 + 过度自信 | L1 halt 状态 + 自动触发 |

**14.2 L5 策略层 = 偏差的"避开"**

- 费率套利（delta 中性）：**减少执行偏差**（不预测方向）但**增加"行动偏差"风险**（98% 时间该观望）
- 大币趋势（波动率目标管理）：**减少过度自信**（波动率目标让仓位不集中）但**增加"代表性偏差"风险**（认为"这次不一样"）
- 禁区黑名单：网格裸跑、马丁、小币动量、高杠杆方向单——直接避开"偏差密度高"的策略类型

**14.3 L6 监控层 = 机制化反行为偏差**

- **飞书告警 = 行为偏差的"闹钟"**——把"该行动/该停下"从人脑的实时判断中剥离，变成预设规则的自动触发
- **日度自动日志 = "决策可见性"**——不让人脑的选择性记忆污染真实记录
- **每周人工复盘 30 分钟 = "偏差校准"**——让"过度自信"被事后核对（"我真的像当初那么确定吗"）
- **结构化日志 = "确认偏差检测"**——所有决策记录留痕，让"我以为我做了 X" vs "实际我做了 Y"有据可查

**14.4 P0-3 数据管道 = 避免"信息过载"**

- 不在 dashboard 里堆砌——只取关键指标（L6 告警清单）
- "信息过载"是行动偏差的近亲——看得多、动得少、错得多
- 架构初稿 L2 数据层的"缺数据标记"（回填 vs 跳过）防止"可得性偏差"（只看到回填好的数据）

**14.5 整体映射：L0-L6 七层 = 反偏差系统**

| 层 | 偏差反制 |
| --- | --- |
| L0 安全 | 跨所分散 + API 最小权限 → 反现状偏好 / 沉没成本 |
| L1 风控 | 禁止清单 + 熔断 → 反过度自信 / 风险反射 / 处置效应 / 沉没成本 |
| L2 数据 | 数据质量 + 缺数据标记 → 反可得性偏差 |
| L3 研究 | 5 关 + CPCV + 马丁签名 → 反过度自信 + 确认偏差 |
| L4 执行 | 幂等 + 对账 + 恢复 → 反注意力偏差 + 现状偏好 |
| L5 策略 | 分阶段 + 禁区黑名单 → 反代表性偏差 + 过度自信 |
| L6 监控 | 飞书告警 + 日度日志 + 复盘 → 反确认偏差 + 行动偏差 + 注意力偏差 |
