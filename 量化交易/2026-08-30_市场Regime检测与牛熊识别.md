## 可复用原则（决策时引用）

1. **regime 错了，再好的策略也是错的**：策略 A 在牛市能赚 30%、在熊市归零；策略 B 在震荡市能赚 15%、在趋势市被反复止损。**regime 错配 > 参数错配**——这是比策略本身更深层的决定。承自《系统思维与反脆弱》§4 + Lo 2004 AMH（regime 决定 alpha 是否存在）。
2. **"regime 不变"的假设永远会错**：传统股票市场 regime 平均持续 5-10 年（1929 / 1970s / 2000 / 2008 四大切换），加密市场 6-18 个月一次切换（2018/2020-03/2021-05/2022 LUNA/2025-10 五大切换）。**默认 regime 会变，是工程纪律**——回测不许用单一长窗口、监控要能识别 regime 切换、风控线要 regime-dependent。
3. **HMM 给出概率，不是确定答案**：HMM 给出的是"当前处于各 regime 的概率"（如 P(牛市)=0.65, P(熊市)=0.30, P(震荡)=0.05），不是"现在一定是牛市"。**阈值化（P>0.7 才认）+ 缓冲（概率翻转前 1-2 期不行动）= 工程纪律**。承自 Wikipedia "Hidden Markov Model" + statsmodels MarkovRegression 的 smoothed_marginal_probabilities 输出。
4. **Hurst 是 regime 的"指纹"**：H ∈ (0.5, 1) = 趋势（动量策略的 regime）；H ∈ (0, 0.5) = 反趋势（均值回归策略的 regime）；H = 0.5 = 随机游走（任何策略都难赚）。**Hurst 与 HMM 互补**——HMM 告诉你"现在在哪"，Hurst 告诉你"这里的策略该是趋势还是反趋势"。
5. **替代方法比 HMM 更适合工程化早期**：滚动波动率分位（20d/60d/120d）、VIX 风格分位、市场宽度（新高新低比）**计算成本低、解释性强、无 EM 局部最优问题**。**HMM 是终审工具，不是日常工具**——日常用 VIX 风格分层 + Hurst；只在策略上线前用 HMM 做 regime 概率的"基线"。
6. **加密的 regime 比传统更频繁、更剧烈、更多重叠加**：24/7 + 杠杆泛滥 + 散户驱动 + 减半周期 + ETF 周期 + 监管周期 = 加密有 6 重周期叠加。**单一 HMM 跑 BTC 日收益可能错过"减半周期"这种慢变量**——需要把 BTC ETF 通过、减半日期、监管反转等"已知日历事件"作为协变量加进 HMM（time-varying transition probabilities, Filardo 1994 风格）。
7. **regime 检测的"早预警"≠"早预测"**：regime 切换在事前不可预测（奈特不确定性），但能在切换**之后 5-10 天**确认。**承认"事后 5-10 天才能确认"，比追求"事前 1 天预测"更可靠**——这对应 VaR/ES 反向压力测试的"找脆弱性"哲学（承自《风险量化 VaR/CVaR/ES》§5）。
8. **regime 动态化熔断 > 静态熔断**：静态熔断（"日亏 -2% 停机"）在牛市太紧（错过行情），在熊市太松（应该 -1% 就停）。**regime-dependent 熔断 = 牛市 -3% / 震荡 -2% / 熊市 -1%**——这对应 ES 反向校准的"regime 分层预算"（承自《风险量化 VaR/CVaR/ES》§7 + 《行为金融》§6.1 确认偏差）。
9. **regime 检测工具按"复杂度 vs 解释性"分层**：VIX 分位 < 滚动波动率 < Hurst < HMM < MS-GARCH < ML 黑箱——**复杂度越高、解释性越差、过拟合风险越高**。100 USDT 项目优先用前三项，后三项作为研究/验证工具。
10. **加密市场最简单的 regime 判据**：30 天均值费率（已在跑）+ 20d 滚动波动率（需新增）+ BTC-ETH 相关系数（需新增）= 三个最便宜的 regime 信号。**"复杂方法在加密里经常输给简单方法"**——HMM 给出的概率可能和"30 天费率均值 ≥ 0.01%"差不多准，但解释性远差。

## 核心逻辑链

1. **前提**：策略的真实表现 = f(策略, regime)。同一策略在牛市/熊市/震荡市表现差异巨大——这不是参数能调的，是**底层概率分布切换**了。
2. **机制**：金融时间序列的"regime 切换"在统计上表现为三个层面同时变化——**均值**（正/负/零）、**方差**（低/中/高）、**相关结构**（独立/弱相关/强相关）。regime 切换不是"事件"，而是**统计特性的突变**；Mandelbrot 1963 棉花价格实证（α ≈ 1.7 稳定帕累托分布）已证明单一统计参数不能跨 regime 通用。
3. **结果**：要识别 regime，需要**隐变量模型**——HMM 用隐藏状态变量 S_t ∈ {牛市, 熊市, 震荡} 解释观测序列 Y_t（收益率/波动率）的统计特性切换。Markov Switching 是 HMM 的连续输出版本（用于收益率序列本身），HMM 更适合离散化场景（如 funding rate 状态、波动率高/中/低）。
4. **方法选择**：① 经典首选 HMM（Gaussian HMM / Statsmodels MarkovAutoregression）—— 概率输出 + 状态解释；② 简单场景用滚动波动率分层（20d/60d/120d 分位）—— 解释性强 + 无 EM 问题；③ 加密特殊场景把日历变量（减半/ETF/监管）作为协变量加进 MS 模型（time-varying transition probabilities）。
5. **项目落地**：P0-3 数据管道加 3 个 regime 字段（隐藏状态 + 状态概率 + Hurst 值）；Phase 1 费率套利升级开仓条件（30 天均值费率 → "30 天均值 + HMM 高费率概率"双判据）；Phase 2 用 regime 切仓位上限和熔断线；L1 风控的 -2% / -10% 升级为 -1%/-1.5%/-2%/-3% 动态分层。
6. **跨周期统一**：regime 检测不是"只在熊市用"，而是**任何时候都跑**——因为"现在不是熊市"也是 regime 的一种状态。承自 Lo 2004 AMH（regime 不是固定的"牛市或熊市"，而是"按时间/制度/参与者结构动态演化的概率分布"）。
7. **诚实声明**：本文**未直接读** Hamilton 1989 Econometrica 全文 + López de Prado AFML 第 7-8 章 + Ang-Bekaert 2002 RFS 原文 + Guidolin 2009 综述；所有具体方法、HMM 公式、statsmodels API、Hurst 计算细节均通过 Wikipedia "Hidden Markov Model" + Wikipedia "Hurst exponent" + Wikipedia "Adaptive market hypothesis" + statsmodels 官方文档 + QuantStart/QuantInsti/QuestDB 工程示例 + 加密 HMM 实证论文交叉验证。

## 分章笔记

### 第一部分　Regime 概念与统计基础

#### 第一章　什么是 Regime + 金融现实例子

**1.1 Regime 的一句话定义**

> Regime（市场状态）= 市场在不同时间窗口有不同统计特性（均值、方差、相关结构、流动性），且转换非随机。

承自 Hamilton 1989 *Econometrica* "A New Approach to the Economic Analysis of Nonstationary Time Series and the Business Cycle"——regime switching 是 GNP 增长在 1953-1984 间呈现"扩张期 / 衰退期"切换的数学抽象；同一框架可移植到金融市场。

**1.2 Regime 的 3 个核心特征**

| 特征 | 牛市典型 | 熊市典型 | 震荡市典型 |
| --- | --- | --- | --- |
| **均值（μ）** | 正（月 +5-10%） | 负（月 -5-15%） | 接近 0 |
| **方差（σ²）** | 中（年化 60-80%） | 高（年化 100-200%） | 低（年化 30-50%） |
| **相关结构** | BTC-ETH ~ 0.5 | BTC-ETH ~ 0.9 | 不稳定 |
| **流动性** | 厚（spread 1-5 bps） | 稀（spread 50-200 bps） | 厚但浅 |
| **典型持仓时间** | 周-月 | 日-周 | 日内-周 |

**1.3 金融现实例子（最坏日回顾）**

承自《自动量化加密货币的成功与失败》§7 + 《风险量化 VaR/CVaR/ES》§6 + Amberdata 2025 报告：

| 事件 | regime 切换类型 | 关键统计变化 |
| --- | --- | --- |
| **1929 大萧条** | 牛→熊（传统市场） | DJ 30 个月跌 89%，vol 跳 10x |
| **1970s 滞胀** | 高波动震荡市 | 标普 500 年化 vol 20%+，CPI 持续 > 5% |
| **2000 互联网泡沫** | 牛→熊 | NASDAQ 78 周跌 78%，vol 跳 3x |
| **2008 金融危机** | 牛→熊 | 标普 vol 跳 5x（年化 80%），相关结构崩塌至 0.9+ |
| **2018 加密熊** | 牛→熊 | BTC 年跌 73%（从 20k 到 3.2k），alt 全灭 |
| **2020-03-12 BTC** | 震荡→崩盘 | BTC 单日 -39%（从 8k 到 4.9k），BitMEX 与 Coinbase 价差 $500+ |
| **2021-05-19 BTC** | 牛→熊 | BTC 单日 -30%（中国监管），24h 清算 80 亿美元 |
| **2022-05 LUNA** | 牛→熊 | UST 脱锚 → LUNA 7 天归零，BTC 月跌 35% |
| **2025-10-10 清算级联** | 震荡→危机 | BTC 1h -20%，全市场 36h 清算 190 亿美元（承自 FTI Consulting 2025-12 报告） |

**1.4 为什么 Regime 检测重要——"策略在错 Regime 下归零"**

**承自《自动量化加密货币的成功与失败》§2-§6 的失败案例逻辑**：

- **趋势策略在震荡市**：被反复止损（每次尝试突破失败都止损出场）→ 累计 5-10% 回撤
- **均值回归策略在趋势市**：连续"抄底在半山腰"（价格不断创新低）→ 累计 30-50% 回撤
- **费率套利在 regime 反转时**：funding rate 突然从 +0.01% 跳到 -0.05%，叠加空腿被 ADL 强平 → 单日 -15% 至 -30%
- **网格策略在单边市**：越跌越买变接飞刀 → 满仓爆仓（参 V2EX 案例 5"ADA 2x 杠杆网格 -40%"）

**承自《行为金融与交易者心理偏差》§6.1 + §6.6**：regime 切换时刻也是行为偏差最严重的时刻——确认偏差让你忽略反向信号、羊群效应让你在最后阶段跟随、FOMO 让你在 regime 切换后追涨。**regime 切换 = 行为偏差密度最高的时段 = 自动化风控最关键的时段**。

**1.5 三类 regime 检测的辨析（避免概念混淆）**

| 概念 | 定义 | 与 regime 的关系 |
| --- | --- | --- |
| **Stationarity（平稳性）** | 均值/方差/自协方差恒定（不随时间变） | **regime 的反面**——平稳 = regime 不变；非平稳常因为 regime 切换 |
| **Structural break（结构断裂）** | 在已知时刻统计特性突变（Chow 1960 test 检测） | 单次断裂，不是反复切换；regime 是多次切换 |
| **Regime switching（状态切换）** | 在 N 个状态间反复切换（Markov 链驱动） | 推广 structural break——断裂点本身是随机的 |

承自 Wikipedia "Structural break" + Hamilton 1989 Econometrica abstract + Chow test 1960：regime switching 是 structural break 的"随机化版本"——regime 切换点本身由 Markov 链生成，不需要预设。

#### 第二章　Regime vs Stationarity vs Structural Break

**2.1 三个概念的层次关系**

```
最广义（最宽松）
↓
Regime switching（状态反复切换，状态数 N，转移矩阵 A）
  ↓
Structural break（一次性/已知次数的断裂，Chow/CUSUM test 检测）
  ↓
Stationarity（无任何断裂/切换，平稳）
```

**2.2 为什么传统时间序列分析不够**

传统 ARIMA/GARCH 模型假设**单一平稳过程**——这意味着：
- 假设 1：均值恒定 → 现实中牛熊切换（均值在 +5% / -10% 间跳）
- 假设 2：方差恒定 → 现实中波动率聚集（GARCH 已部分解决，但仍假设"聚集模式不变"）
- 假设 3：参数不变 → 现实中 regime 切换参数必变

**结果**：传统 ARIMA 在 regime 不变时预测准确，regime 切换时**预测残差跳 5-50 倍**。承自《回测方法论深化与 CPCV》§6.1 加密收益非平稳性。

**2.3 Structural Break 的检测方法**

承自 Wikipedia "Structural break" + Chow 1960：
- **Chow test**：在已知断裂点 T₀ 处检验"前后回归参数是否相等"
- **CUSUM test**：在未知断裂点处检验"累计残差是否超出置信带"
- **Bai-Perron 多断裂点测试**：自动检测 N 个断裂点

**加密应用**：
- **2024-01 BTC ETF 通过** = 结构性断裂（资金结构永久改变）
- **2025-10 清算级联** = 短暂 regime 切换（不是永久断裂，几周后回到震荡）
- **regime switching model 适合后者**——能建模"暂时进入危机态 + 之后回到常态"的反复过程

**2.4 加密市场为什么不能只看 structural break**

承自 §2.2 + 加密特殊性（第三章）：
- 加密市场 regime 切换**没有明确的"断裂点"**——是连续渐变（funding rate 从 +0.01% 慢慢到 0% 再到 -0.01%）
- 即使有断裂（如 LUNA），regime 切换**没有预先知道**——只能事后识别
- 单一 HMM 是连续 + 自动识别 + 概率输出——是 structural break 的"加密适配版"

### 第二部分　经典方法（必含）

#### 第三章　HMM（隐马尔可夫模型）核心算法（必含）

**3.1 HMM 的 5 大要素**

承自 Wikipedia "Hidden Markov Model" + Rabiner 1989 IEEE 经典教程：

| 要素 | 符号 | 含义 |
| --- | --- | --- |
| **状态数** | N = {1, 2, ..., K} | 隐藏状态集合（牛市/熊市/震荡 = 3 状态） |
| **初始概率** | π = (π₁, ..., π_K) | 起始时各状态的概率 |
| **转移概率** | A = [a_ij]（K×K 矩阵） | 从状态 i 转到状态 j 的概率 |
| **发射概率** | B = {b_i(y_t)} | 在状态 i 下观测 y_t 的概率密度 |
| **观测序列** | Y = (y_1, ..., y_T) | 可见的时间序列（收益率、波动率） |

**关键假设（Markov 性质）**：
```
P(S_t | S_{t-1}, S_{t-2}, ..., S_1) = P(S_t | S_{t-1})
P(Y_t | X_1:T) = P(Y_t | X_t)     # 观测只依赖当前状态
```
状态序列是 Markov 链；观测只依赖当前状态（"条件独立于历史"）。

**3.2 三大经典问题**

承自 Wikipedia "Hidden Markov Model" + Rabiner 1989：

| 问题 | 已知 | 求 | 算法 |
| --- | --- | --- | --- |
| **评估（likelihood）** | 模型参数 λ | 观测序列 Y 的概率 P(Y\|λ) | **前向算法**（Forward Algorithm） |
| **解码（decoding）** | 模型参数 λ + 观测序列 Y | 最可能状态序列 argmax P(S\|Y, λ) | **Viterbi 算法** |
| **学习（learning）** | 观测序列 Y | 模型参数 λ = (π, A, B) | **Baum-Welch 算法**（EM 算法的特例） |

**3.3 Baum-Welch 算法的工程细节**

承自 Wikipedia "Hidden Markov Model" + QuantInsti/QuestDB 工程示例：

```python
from hmmlearn.hmm import GaussianHMM
import numpy as np

# 输入：BTC 日收益率序列（reshape 为 (T, 1)）
returns = btc_daily_returns.values.reshape(-1, 1)

# 训练：3 状态 GaussianHMM
model = GaussianHMM(
    n_components=3,        # 牛/熊/震荡 = 3 状态
    covariance_type="full",
    n_iter=1000,
    tol=1e-4,
    random_state=42,
).fit(returns)

# 输出：每个时刻各状态的概率（shape = (T, 3)）
probs = model.predict_proba(returns)
# 输出：每个时刻最可能状态（Viterbi 解码）
states = model.predict(returns)
# 输出：模型参数
print(f"Transition matrix A:\n{model.transmat_}")
print(f"Means (各状态均值):\n{model.means_.flatten()}")
print(f"Variances (各状态方差):\n{model.covars_.flatten()}")
```

**3.4 Baum-Welch 的关键陷阱**

承自 Wikipedia "Hidden Markov Model" + QuantInsti 工程实践：

1. **局部最优**：Baum-Welch 是 EM 算法特例，**只能保证局部最优**。工程上要 `n_init=30` 多次初始化取对数似然最高的。
2. **标签切换问题**（label switching）：HMM 学出的"状态 1"不一定是"牛市"——可能是任何状态。**通过后处理（按均值排序）固定标签**：
   ```python
   # 按状态均值降序排序，让状态 0 = 高收益、状态 2 = 低收益
   order = np.argsort(model.means_.flatten())[::-1]
   state_map = {old: new for new, old in enumerate(order)}
   states_mapped = np.array([state_map[s] for s in states])
   ```
3. **状态数 K 的选择**：用 BIC（贝叶斯信息准则）——
   ```python
   bic = -2 * model.score(returns) + K**2 * np.log(T)
   # 选 BIC 最小的 K
   ```

#### 第四章　Markov Switching 模型（AR-MS）

**4.1 AR-MS 的一句话定义**

> 在不同 regime 下用不同的 AR(p) 参数——regime 切换是参数空间的切换，不是观测的离散化。

承自 Hamilton 1989 Econometrica 原文 abstract + statsmodels 官方文档 MarkovAutoregression：

```python
# Hamilton 1989 原始论文的 statsmodels 复现
# 1953-1984 美国实际 GNP 季度数据，2 regime AR(4) 切换模型
from statsmodels.tsa.regime_switching.tests.test_markov_autoregression import rgnp
dta = pd.Series(rgnp, index=pd.date_range('1951-04', '1984-10', freq='QS'))

mod_hamilton = sm.tsa.MarkovAutoregression(dta, k_regimes=2, order=4, switching_ar=False)
res_hamilton = mod_hamilton.fit()
# 输出：2 状态 AR(4)——一状态对应"扩张期"，另一对应"衰退期"
```

**4.2 AR-MS vs HMM 的关键区别**

| 维度 | HMM | AR-MS |
| --- | --- | --- |
| **输出类型** | 离散（高斯/多项分布） | 连续（AR 残差） |
| **观测含义** | 离散化收益/波动率 | 收益序列本身 |
| **适合场景** | 波动率 regime + funding rate 状态 | 收益率 regime（牛/熊/震荡） |
| **典型 N** | 2-3 状态 | 2-3 状态 |
| **参数数量** | 较少（n_components × covariance） | 较多（n_components × AR(p) 系数） |
| **训练难度** | EM 局部最优 | EM 局部最优（更严重，因参数多） |

**5.2 Hurst 指数（趋势 vs 均值回归的"指纹"）**

承自 Wikipedia "Hurst exponent" + macrosynergy.com Hurst 实证研究：

```python
# 安装 fathon 或 hurst 包
# pip install fathon  # 或 pip install hurst

from hurst import compute_Hc

hurst, c, data = compute_Hc(returns, kind='price', simplified=True)

# 解释：
# H ∈ (0.5, 1) → 趋势（动量策略生效）→ regime = "trend"
# H = 0.5      → 随机游走（任何策略都难）→ regime = "random"
# H ∈ (0, 0.5) → 反趋势（均值回归生效）→ regime = "mean_reverting"
```

**数学定义**（Wikipedia Hurst exponent）：
```
E[R(n)/S(n)] = C · n^H    as n → ∞
```
其中 R(n) 是 n 期累计偏差的 range，S(n) 是 n 期标准差的累积。

**R/S 算法估计**（Anis-Lloyd 修正）：
1. 计算序列均值 m
2. 减去均值得到 Y_t = X_t - m
3. 计算累积偏离 Z_t = Σ_{i=1..t} Y_i
4. 计算 range R(n) = max(Z) - min(Z)
5. 计算标准差 S(n)
6. 计算 R(n)/S(n)，对 n 取对数回归，斜率 = H

**置信区间**（Weron 2002 bootstrap）：
- 95% CI ≈ 0.5 ± exp(-7.33 log(log N) + 4.21)
- 子序列长度需 n > 50 才能稳定估计

**加密的 Hurst 经验值**：
- BTC 日收益率 Hurst ≈ 0.50-0.55（接近随机游走，弱趋势）
- BTC 1h 收益率 Hurst ≈ 0.55-0.65（中等趋势）
- BTC funding rate Hurst ≈ 0.70-0.85（强趋势——funding rate 自相关强）

def classify_regime_composite(row):
    """
    综合 5 个指标做 regime 分类
    优先级: crisis > bear > bull > sideways
    """
    # Crisis 检测
    if row['btc_eth_corr_30d'] > 0.85 and row['vol_20d_pct'] > 0.85:
        return 'crisis'  # 高相关 + 高波动 = 危机态

    # Bull 检测
    if row['vol_20d_pct'] < 0.5 and row['hmm_state'] == 0 and row['hurst_20d'] > 0.55:
        return 'bull'
    
    # Sideways（默认）

**11.2 Regime 切换的过渡期处理**

- **平滑过渡**：regime 从 bull 切到 sideways 时，熔断线在 5 天内渐进收紧（-3% → -2.5% → -2%）而非瞬间切换
- **二次确认**：regime 主概率需要 ≥ 0.6 + 连续 2 天确认，才触发熔断线切换
- **异常跳过**：regime 标签 1 天内突变（如 bull → crisis）需人工 review

**11.3 Regime 检测失效的兜底**

```python
def circuit_breaker_with_regime(regime_state, confidence, base_daily=-0.02, base_dd=-0.10):
    """
    regime 检测失效的兜底：
    - confidence < 0.6 → 用最严格的熔断线（crisis 默认）
    - 数据缺失 → halt
    """
    if regime_state is None or confidence < 0.6:
        # regime 不确定 → 用最保守
        return {'daily': -0.01, 'drawdown': -0.05}
    
    # regime 正常 → 按 regime 设置
    regime_breakers = {
        'bull': {'daily': -0.03, 'drawdown': -0.15},
        'sideways': {'daily': -0.02, 'drawdown': -0.10},
        'bear': {'daily': -0.015, 'drawdown': -0.07},
        'crisis': {'daily': -0.01, 'drawdown': -0.05},
    }
    return regime_breakers.get(regime_state, {'daily': -0.01, 'drawdown': -0.05})
```

```python
def simple_regime_indicator(df):
    """
    三个最便宜的 regime 指标 + 综合判据
    不需要 HMM，不需要 EM，解释性强
    """
    # 指标 1: 30 天均值 funding rate（已在跑）
    funding_30d = df['funding_rate'].rolling(30 * 3).mean()  # 30 天 × 3 结算/天
    
    # 指标 2: 20d 滚动波动率分位（新增）
    vol_20d = df['returns'].rolling(20).std() * np.sqrt(365)
    vol_pct = vol_20d.rolling(252).rank(pct=True)
    
    # 指标 3: BTC-ETH 30d 相关（新增）
    btc_eth_corr = df['btc_returns'].rolling(30).corr(df['eth_returns'])
    
    # 综合判据
    def label(row):
        if pd.isna(row['vol_pct']) or pd.isna(row['btc_eth_corr']):
            return 'unknown'
        if row['btc_eth_corr'] > 0.85 and row['vol_pct'] > 0.85:
            return 'crisis'
        if row['funding_30d'] >= 0.0001:           # ≥ 0.01%
            if row['vol_pct'] < 0.5:
                return 'bull'
            else:
                return 'sideways'
        if row['funding_30d'] < -0.0001:          # < -0.01%
            return 'bear'
        return 'sideways'
    
    df['simple_regime'] = df.apply(label, axis=1)
    return df
```
